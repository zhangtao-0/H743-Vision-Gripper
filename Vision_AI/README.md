## 学习与项目导航

| 文件夹 | 你在这里找什么 |

| Docs | 00方案；01环境；02准备；03运行；04采集；05安装审批；06资源选型；验收报告 |

| training/evaluation | 后续训练/评价进入条件和约定；本轮不启动训练 |

第一批按用户确认的圆柱/矩形/L型；旧Host快递工具保留，不能直接混用类别。既有[电脑采图入口](../Host/vision_gripper/README.md)和[旧视觉文档](../Docs/视觉识别与抓取/README.md)可继续查阅。

最初复现只读使用原Host环境；用户已批准基础依赖，现已安装到Vision_AI/.venv并独立复验通过。双击教学入口优先使用这个独立环境。所有坐标Pixel、grasp_valid=false，不是毫米抓取点。
