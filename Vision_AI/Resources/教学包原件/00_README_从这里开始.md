# 三指机械夹爪视觉抓取：从这里开始

**研究方向：** B｜多形状工业工件的视觉识别与三指自适应稳定抓取。

## 最合适的打开顺序

1. 阅读 `01_三指视觉抓取_零基础到复现实战教学书.docx`（Word；Markdown 版可直接交给 Codex）。
2. 学第一篇、第 3–5 章，再打开 `03_最小可运行演示/README.md` 执行第一个**不用 GPU、摄像头、模型训练**的练习。
3. 阅读 `02_开源复现路线与资源清单.md`，按 OpenCV → CVAT → Ultralytics 的次序逐步复现。
4. 准备与 Codex 联动时，把 `04_Codex_分阶段执行与验收指令.md` 交给 Codex，并指定一个**独立的新视觉研究目录**；不要让它直接修改已有 STM32/IAR 固件工程。

## 本包包含

- **教学书 Word + Markdown**：含学习内容、12 周教学计划、训练和标定、抓取规划、H743 协同、AI 协作与验收要求。
- **开源复现清单**：官方网站、仓库、复现顺序、许可限制和适配风险。
