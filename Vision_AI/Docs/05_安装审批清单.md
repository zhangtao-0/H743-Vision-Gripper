## A包：独立基础视觉环境（已批准、已完成）

用途：让研究目录脱离旧Host环境独立运行。来源PyPI官方索引，固定本轮已实际验证的wheel版本：numpy2.5.4、opencv-python4.14.0.94、Pillow12.3.0。具体依赖见requirements-baseline.txt，下载量由wheel/平台/缓存决定，通常几十至数百MB，不给虚假精确数字。

批准后执行：

```powershell
# 在H743项目根目录
& .\Vision_AI\.venv\Scripts\python.exe -m pip install -r .\Vision_AI\requirements-baseline.txt
& .\Vision_AI\.venv\Scripts\python.exe -m pip check
& .\Vision_AI\.venv\Scripts\python.exe -m unittest discover -s .\Vision_AI\tests -v
```

安装失败保留pip日志，不对旧环境补丁。已有主机测试通过不能替代新venv安装后的复验。

## B包：GPU训练环境（后续单独批准）

用途：利用RTX4060训练小型分割模型。优先PyTorch官方Windows pip二进制包，按官方选择器选CUDA12.6及匹配torch/torchvision；安装到研究venv，保存解析版本与pip freeze。官方源https://download.pytorch.org/whl/cu126，Ultralytics固定8.4.184见requirements-training.txt。PyTorch下载可能为数GB，加依赖和缓存需预留数十GB；不默认额外安装系统CUDA Toolkit或Visual Studio编译链。

批准后先核验可解析wheel版本与驱动兼容、pip下载哈希，再安装；不得复用此前失败下载或绕过校验。验收torch.cuda.is_available()==True、设备名称正确、小张量运算成功、pip check通过，才可称GPU环境就绪。当前2.14.1+cpu只能CPU，不能称CUDA已成功。

## C包：一个官方小权重（后续单独批准）

用途：1～3张样本预训练推理工具链验证。建议YOLO26n-seg，与本包新版官方教程一致，官方文档https://docs.ultralytics.com/tasks/segment/及ultralytics官方assets。批准下载时记录确切release/URL/字节数/哈希；本轮尚未锁定具体权重文件的哈希，因此不自动下载。COCO预训练类不保证有你的三类工件；这只是工具验证，不是自定义模型完成。

旧Host的yolo11n-seg默认不更改，今后用--weights加载你明确训练的文件。比较模型时保持数据集、指标、输入尺寸一致，不靠名字更新宣称更好。
