# 第一次运行：你该看到什么

这里已跑过一次，不需要先买软件、安装CUDA或连接板子。原图是程序画的三形状，标为synthetic；不是摄像头拍摄。

## 最快入口

双击研究目录的“启动教学演示.cmd”。它借用现有Host解释器启动，优先检测新.venv是否具备基础依赖；不具备时只读使用旧环境。每次创建新的实验目录，输出原版复现、8种场景及三联图；不会联网下载模型，也不会访问串口。若搬移项目导致旧解释器路径失效，按05手册安装独立环境。

从H743项目根目录也可在PowerShell运行：

```powershell
$vp = '.\Vision_AI\.venv\Scripts\python.exe'
& $vp .\Vision_AI\tools\study.py test
& $vp .\Vision_AI\tools\study.py demo
```

## 按这个顺序看本次结果

1. 打开[正常工况三联图](../experiments/20261024_baseline_v1/normal/comparison.png)：左原图，中白色候选物体/黑色背景，右绿色旋转外框、红色质心、蓝色内部示意点。
2. 打开[识别JSON](../experiments/20261024_baseline_v1/normal/detections.json)：coordinate_system=Pixel，左上角为原点，x向右、y向下。圆的中心约(148,138)，这是图像位置，不是毫米。
3. 注意L型：红点可能在凹槽外，蓝点在轮廓内。内部点仍不等于三指可靠接触点；没有机械几何、标定和力学信息，所以所有grasp_valid=false。
4. 看[暗背景失败](../experiments/20261024_baseline_v1/dim_background_fixed_threshold/comparison.png)：白色几乎铺满图像，算法拒绝触边背景，物体数0。再看[同输入调阈值](../experiments/20261024_baseline_v1/dim_background_threshold_retuned/comparison.png)：局部恢复3个，只能说明这张图参数合适，不能称泛化准确率提高。
5. 看[遮挡误判](../experiments/20261024_baseline_v1/occluded_circle/comparison.png)：剩余圆弧被规则分成block；正好说明以后要用真实样本与学习模型比较。

算法步骤：读BGR图→灰度或HSV→阈值掩码→3×3开运算去小噪声→轮廓面积过滤→圆度/实心度粗分形状→质心/外框/方向→JSON和三联图。shape_hint是规则推断，不含神经网络置信度。近圆/近方形角度标记为不确定，不能强行解释成明确姿态。

## 换真实照片

先把照片复制到datasets/raw/一个新会话目录，例如session_01。不要把模拟图放进去。下面示例里的sample01.png需换为真实存在的文件，从H743项目根目录运行：

```powershell
$vp = '.\Vision_AI\.venv\Scripts\python.exe'
& $vp .\Vision_AI\tools\study.py photo --input .\Vision_AI\datasets\raw\session_01\sample01.png --output .\Vision_AI\experiments\real_sample01
```

若是H743的240×240图像，可额外传`--config .\Vision_AI\configs\camera_240.json`，面积阈值降到100；640×480样例的800像素阈值不能不加判断地套到低分辨率小物体上。每次输出必须用新目录，已存在就报错，避免覆盖证据。

学习任务：你先指出掩码有没有正确选中物体，再看分类。掩码错时优先检查光照、背景、阈值；不要一上来调PID或认为神经网络安装坏了。
