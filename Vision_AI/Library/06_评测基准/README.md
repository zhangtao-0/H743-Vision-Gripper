# 测试基准分域

当前taco_containers_v1是公开真实照片的30train/9val/9test，所有同一图片实例共用split，精确文件SHA不跨split。公共采集会话未知，不能声称已排除全部相似场景泄漏。今后还需近重复检查和来源场景/实物分组。

测试集用于候选训练完成后的报告，不参与epoch选择或超参数调整。正式新研究任务需要单独冻结H743实拍benchmark，至少30张只是发布规则的起步门槛，数量本身不保证精度。测试标注有错需创建新基准版本并保留原因，不悄悄修标签换高指标。

本次9test共11目标；conf0.25实际保存2个检测，仅1张图有检测，8张无检测。Mask mAP50约0.3733、mAP50-95约0.2967；平均指标不代表每类都可用，更不是抓取成功率。候选拒绝发布原因：低于mAP50门槛且H743基准缺失。

模型原始日志、训练CSV、原始预测和指标均保存在experiments/auto_*，模型台账保存确切路径/权重SHA。faster-coco-eval可选包缺失而自动安装被关闭，当前为Ultralytics原生指标，不声称完成第三方COCO评价器交叉核验。
