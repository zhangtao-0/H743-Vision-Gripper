## 现有本地资产

TACO48张真实原图，约74.66MB，目标实例82个；预训练YOLO26n-seg约6.72MB。原标注细类保留，训练只做cup/box/bottle三组，绝不把箱子或杯子重命名为L型。许可按官方条款逐图登记：缺省图片条目CC BY4.0，原标注CC BY4.0，代码MIT。代码许可不当成图片许可。来源、作者/贡献者说明与原网址保留于taco_downloads.json。

TACO有自然场景、垃圾/变形容器和很小目标，与H743台面工业工件有明显差异。预览图标“contains cup”等表示图中有该类别，不表示整张照片只有该物体；绿色轮廓为原标注。它适合启动流程和保留广义类别，不能代替本机工件精度与三指接触数据。

用户实拍仍放在Vision_AI/datasets/raw，后续通过源目录登记接入，不搬动或覆盖已有原件。资料库中的图片/权重默认不自动上传Git或云服务。每次下载有限额，失败保留日志；新标签定义写本体/规则，新数据生成版本，不改冻结test。

本轮已实际完成2epoch CPU短训练，只登记候选、未发布；操作与限制见[完整手册](../Docs/08_多层标签与自主训练手册.md)。
