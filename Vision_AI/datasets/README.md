# 数据原件与版本

当前本目录没有用户实拍工件数据；公开真实图像与冻结训练版本已建在[Library](../Library/README.md)，二者分域管理。第一批按用户确认的圆柱/矩形/L型，每类选1～3个轻质实物；类别ID见../configs/classes.json，不能复用旧carton/black_parcel的ID语义。

raw/session_id/保持原始照片方向，annotations/session_id/存人工标注原件。每次实验使用新版本目录。不要覆盖原图或删除失败样本。合成实验图在experiments，不放入raw，不自动进入训练集。

先拍10～30张做传统视觉排障，再分5个以上独立拍摄会话收集100～300张做训练流程。每会话覆盖不同位置/距离/照明，按会话分组，测试实物若需要评估泛化也必须独立。数量只是起点，不保证精度。raw/和annotations/默认Git忽略，另做本地备份，不自动上传。
