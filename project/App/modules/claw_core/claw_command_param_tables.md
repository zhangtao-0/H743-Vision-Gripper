# 机械夹爪常用指令表与默认参数表

> 历史参考提示（2026-10-22）：本表含F103旧PWM引脚、当前不存在的参数ID21–25及位置模式帧校验D7等偏差。H743现用协议以[统一指令手册](../../../../Docs/指令手册/README.md)为准；本表正文保留用于历史对照。

## 一、按键动作

| 按键 | 触发 | 动作 |
|---|---|---|
| A0 / PA0 | 单击 | 运动中立即停止；静止时按当前共同范围闭合。 |
| A0 / PA0 | 双击，350ms 内连续两次 | 张开到已保存张开极限。 |
| A0 / PA0 | 单独长按 3000ms | 进入 A0/B0/滑块共同范围选择。 |
| B0 / PB0 | 稳定按下 | 普通模式立即按当前范围连续往复扫描。 |
| B0 / PB0 | 松开 | 停止扫描，并保持当前位置。 |
| B0 / PB0 | 双击 | 立即反向；未扫描时从当前动作反方向接管。 |
| A0 + B0 | 同时长按 3000ms | 进入极限标定；标定中再次同时长按 3000ms 校验、保存并退出。 |
| 极限标定中的 A0 | 单击 / 双击 | 记录夹取端 / 张开端。 |
| 极限标定中的 B0 | 长按 / 松开 / 双击 | 低速扫描 / 停止 / 换向。 |
| 范围选择中的 B0 / A0 | 单击 | B0 切换候选；A0 保存候选并退出。 |

## 二、官方飞特协议常用帧

说明：官方帧格式为 `FF FF ID Length Instruction Params CheckSum`。多字节数据低字节在前。

`Length = Params字节数 + 2`；`CheckSum = ~(ID + Length + Instruction + Params之和) & 0xFF`。

| 功能 | 十六进制帧 | 说明 |
|---|---|---|
| PING ID=1 | `FF FF 01 02 01 FB` | 查询 ID1 是否在线；正常返回 `FF FF 01 02 00 FC`。 |
| 读当前位置 | `FF FF 01 04 02 38 02 BE` | 从 0x38 读 2 字节当前位置。 |
| 读综合反馈 | `FF FF 01 04 02 38 0F B1` | 从 0x38 连续读 15 字节，覆盖位置、速度、负载、电压、温度、moving、电流。 |
| 写目标位置，手册格式 | `FF FF 01 09 03 2A 00 08 00 00 E8 03 D5` | 位置 2048，时间 0，速度 1000。 |
| 写目标位置，项目扩展格式 | `FF FF 01 0A 03 29 00 00 08 00 00 E8 03 D5` | 从 0x29 写加速度、位置、时间、速度；项目 `SetAngleEx` 使用这种格式。 |
| 扭矩上力 | `FF FF 01 04 03 28 01 CE` | 写 0x28=1，使能舵机扭矩。 |
| 扭矩卸力 | `FF FF 01 04 03 28 00 CF` | 写 0x28=0，释放舵机扭矩。 |
| 设置位置模式 | `FF FF 01 04 03 21 00 D7` | 写 0x21=0，位置控制模式。 |
| 广播 ACTION | `FF FF FE 02 05 FA` | 执行 REG_WRITE 异步写入内容。 |

## 三、本地扩展指令

说明：本地扩展指令仍使用 `FF FF FE Length Instruction Params CheckSum` 外形，但只给 STM32 本机解析，不转发给舵机。

控制来源规则：按键、VOFA、蓝牙处于同一等级，最新运动命令覆盖旧命令。外部目标到来后停止旧本地目标周期重发；下一次按键动作可立即重新接管。参数、PING、READ 和状态打印不抢占，不设超时自动恢复，也不需要手动交换控制权。

| 功能 | 十六进制帧 | 说明 |
|---|---|---|
| 开启 claw 打印 | `FF FF FE 03 F0 01 0D` | 周期打印位置、目标、电压、电流。 |
| 关闭 claw 打印 | `FF FF FE 03 F0 00 0E` | 默认状态；反馈和 OLED 仍更新。 |
| 单次打印 claw | `FF FF FE 03 F0 02 0C` | 不改变周期开关，只打印一次。 |
| 打印指令示例 | `FF FF FE 02 F1 0E` | 输出常用官方帧和本地帧示例。 |
| 列出全部参数 | `FF FF FE 03 F2 00 0C` | 输出参数 ID、名称、当前值、默认值、范围。 |
| 查询单个参数 | `FF FF FE 04 F2 01 ID CS` | 例：查询 OPEN_SPEED，ID=04，需重新计算校验。 |
| 设置 OPEN_SPEED=900 | `FF FF FE 06 F2 02 04 84 03 7C` | 参数 ID=4，值 900，即 0x0384。 |
| 设置 SWEEP_STEP_MS=40 | `FF FF FE 06 F2 02 08 28 00 D7` | 参数 ID=8，值 40ms。 |
| 恢复单个参数默认值 | `FF FF FE 04 F2 03 ID CS` | action=03。 |
| 恢复全部参数默认值 | `FF FF FE 03 F2 04 08` | action=04。 |
| F3 旧命令兼容 | `FF FF FE 03 F3 00 0B` | 仅提示“最新运动命令自动生效”，不改变运行状态。 |
| 查询机械极限 | `FF FF FE 03 F4 00 0A` | 返回标定状态、极限有效性和共同动作范围。 |
| 进入极限标定 | `FF FF FE 03 F4 03 07` | B0 长按扫描；A0 单击记闭合端，双击记张开端。 |
| 取消极限标定 | `FF FF FE 03 F4 04 06` | 丢弃本轮打点，保留旧极限。 |
| 清除机械极限 | `FF FF FE 03 F4 05 05` | 清除 Flash 极限；之后需重新标定。 |
| 校验并保存机械极限 | `FF FF FE 03 F4 06 04` | 两端均有效时写入 Flash 并退出标定。 |

### F5：VOFA/蓝牙动态控件帧

固定格式：`FF FF FE 07 F5 Cmd %% 00`。`%%` 是 4 字节 IEEE754 小端 float；末尾 `00` 仅是 F5 模板尾字节，不适用于普通官方帧。

| Cmd | 功能 | VOFA 模板 | 说明 |
|---:|---|---|---|
| 00 | 角度滑块 | `FF FF FE 07 F5 00 %% 00` | 滑动时持续发送当前角度；新目标覆盖旧目标。 |
| 01 | A0 | `FF FF FE 07 F5 01 %% 00` | 按下 1.0=`00 00 80 3F`，松开 0.0=`00 00 00 00`。 |
| 02 | B0 | `FF FF FE 07 F5 02 %% 00` | 按下 1.0，松开 0.0。 |
| 03 | 共同范围 | `FF FF FE 07 F5 03 %% 00` | 0.0=机械极限，1.0=0~270度。 |

## 五、最新命令显示

OLED 中的 `OWNER` 仅表示最近一次运动命令来源，不需要人工切换：

| 字段 | 含义 |
|---|---|
| OWNER=KEYA | A0 正在控制。 |
| OWNER=KEYB | B0 正在控制。 |
| OWNER=VOFA/BT/USB | 上位机、蓝牙或外部官方帧正在控制。 |
| OWNER=SAFE | 安全保护控制。 |

## 六、排查提示

如果 OLED 上只有 TG 和状态变化，A/I/U/L 不变化，优先检查 USART2 RX 是否收到舵机返回。本版已把周期反馈读取改为短超时等待回读，若仍不变化，应检查舵机 ID、波特率、TX/RX 接线、TTL 模块方向、舵机供电和 `HAL_UART_RxCpltCallback()` 是否分发到 `FeetechStsBus_HandleRxComplete()`。
