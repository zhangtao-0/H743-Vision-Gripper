## 当前最需要记住的结论

- 开发板使用稳定 **5V 输入**，或依说明采用独立 **3.3V 直供**，两条供电路径择一。USB、ST-Link/USB-TTL 电源脚和外部电源之间要核查是否会并联、回灌。
- STS3215-C001 当前官方产品页列 **6–7.4V**；MG310 参数截图标称 **7.4V、建议 7–13V**，编码器却是 **3.3–5V**。三个范围不能混用。
- 两节普通锂离子电池标称 7.4V、常见满充 8.4V。当前资料不足以把它作为 C001 的已确认直连电源；按稳压后的实际输出选供电。
- 用户已确认当前为 JDY-31，底板与固件版本待确认；HC-08 V3.1 是 BLE 模块。UART 一样不代表手机端协议相同，也不代表 VCC 可以照搬。
- 当前仍没有已安装 H 桥的证据。MG310 动力线不能接开发板 GPIO 或拿 GPIO 当电机电源，保持 `MOTOR_DRIVER_PROFILE=0`。

这次只整理档案和教学资料，没有改动固件、执行 AT 配置、改接线或进行新的物理测试。返回[项目教学手册](../教学手册/README.md)、[项目卡片](../../../../00_项目库导览/01_H743项目卡片.md)。
