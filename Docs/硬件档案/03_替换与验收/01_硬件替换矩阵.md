# 硬件替换时：保留什么，核对什么，改哪里

“可替换”应分别判断机械、电源、电气、协议、软件和验收六项。只有每项都相容，才能考虑不改代码的替换。下面提供检查入口，不代表候选设备已经被实物验证。

| 更换对象 | 有条件保留 | 必须重新核对/可能修改 | 当前判断 |
|---|---|---|---|
| USB 改外部电源 | 主板初始化与业务 | 稳压 5V/3.3V择一、功率预算、防回灌、接头极性 | 架构可用，具体电源未选型/未测 |
| 2S 电池代替固定7.4V源 | 系统业务目标 | 充满8.4V/欠压范围、DC-DC、BMS、执行器允许电压 | 不能按标称值直接接主板/C001 |
| JDY-31 → HC-08 | USART3及有效字节流业务协议 | 核心/底板电压、9600/8N1、SPP→BLE App/GATT、AT语法、分包延迟 | 需要适配无线端；未证明直接拔插兼容 |
| STS C001 → 另一总线舵机 | 部分业务接口 | TTL/RS485、电源、机械、协议寄存器、ID/波特率、位置单位、反馈 | 逐型号审查；不能只按家族名替换 |
| STS → PWM 舵机 | 上层角度目标概念 | 驱动类别、反馈能力、供电、机械行程、PWM合法脉宽 | 不是同一驱动直接替换 |
| MG310 霍尔 → GMR | PID控制结构 | 13PPR→500PPR、CPR、计数频率、反馈方向/电平、整定 | 软件支持配置；要实测单位与闭环 |
| MG310 → 其他减速电机 | 状态机/PID模块接口 | 电压电流、减速比、PPR、最高RPM、负载惯量、保护、H桥和增益 | 需重新标定与功率评估 |
| H桥型号变化 | 电机业务API | VM/3.3V阈值、真值表、限流、PWM、STBY、制动/滑行 | 选择对应profile，默认保持0 |
| 1.54 SPI屏 → 其他SPI屏 | 绘图API部分 | 屏控、针序/电平、尺寸偏移、像素格式、初始化、背光 | 尺寸/接口名相同不足以确认 |
| FD5640 → OV2640/另一摄像头 | 采集服务的分层思路 | 电源/FPC、时钟、ID/SCCB、同步/格式、DMA内存 | 用对应驱动配置并复验，不支持任意模块 |
| EC11 → 其他旋钮 | 调速事件语义 | 裸件/模块电平、边沿数、去抖、方向 | 通常配置即可，需计数实验 |
| QSPI Flash → 同封装其他芯片 | 存储上层接口 | VCC、容量/ID、命令/QE、擦除粒度、地址宽度 | 按数据表和驱动核对 |

## 从硬件条件落到代码

- 波特率：[board_config.h](../../../project/App/platform/boards/lxb743zi_p1/board_config.h)；角色到句柄：[board_resources.c](../../../project/App/platform/board_resources.c)；GPIO/时钟/外设：[main.c](../../../project/Core/Src/main.c)、[MSP](../../../project/Core/Src/stm32h7xx_hal_msp.c)及 IRQ 路由。角色映射不能代替硬件初始化。
- 蓝牙业务帧：[bsp_bluetooth.h](../../../project/App/bsp/bsp_bluetooth.h)、[feature_config.h](../../../project/App/config/feature_config.h)。手机/GATT代码属于无线客户端，不由 MCU 的 UART 速率宏决定。
- 电机：[motor_config.h](../../../project/App/config/motor_config.h)，然后阅读[电机调用链](../../教学手册/02_数据与控制链路/03_电机闭环与EC11调用链.md)。换CPR和驱动条件后必须验证符号/单位，不直接复用旧PID验收结论。
- 摄像头/屏幕：先读[视觉调用链](../../教学手册/02_数据与控制链路/02_图像帧从摄像头到屏幕.md)，区分传感器寄存器、采集、缓冲与显示，避免只在应用层修补颜色或尺寸。

先保存旧硬件与固件版本，做单设备最小实验，再做组合验收。一次替换多个设备会失去故障对照；“插头相同”和“能编译”都不是最终判据。
