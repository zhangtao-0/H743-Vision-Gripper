# 硬件总清单与用途

“使用状态”来自用户反馈、板卡原理图和当前工程，三者分别标注。数量未现场盘点；不能把固件支持的设备都登记为已购买。电压摘要用于索引，具体接法见对应档案。

| 编号 | 设备/型号 | 用途 | 状态与数量口径 | 电源与注意点 |
|---|---|---|---|---|
| HW01 | 鹿小班 LXB743ZI-P1，STM32H743ZIT6 | 主控，组织视觉、控制、通信、存储 | 用户实物，至少 1 块 | 5V/USB 或 3.3V 直供择一；[供电说明](../01_供电设计/01_开发板与整机供电.md) |
| HW02 | Type-C 数据线与电脑 USB 口 | 当前板卡供电、USB CDC/DFU | 用户确认 USB 供电，线缆数量待盘点 | USB 口连接 MCU，不是板载 USB-UART；普通 USB 供电能力不覆盖动力负载 |
| HW03 | ST-Link，具体版本待登记 | SWD 下载、调试、读寄存器 | 历史已连接，当前是否连接待确认 | 目标电压检测与电源输出要区分，不能盲接 5V/3.3V 输出 |
| HW04 | USB-TTL/串口工具，具体型号待登记 | USART1 上位机、日志和 VOFA | 代码和历史串口使用；独立转换器实物型号未确认 | 3.3V UART 逻辑；仅接 TX/RX/GND 时也须避免目标断电后的信号回灌 |
| HW05 | FD5640-500w-V11，OV5640 模块 | DCMI 图像采集 | 用户确认，有历史动态预览证据 | 本板 FPC 接口 3.3V；模块内部核心电源不等于接口 VCC |
| HW06 | 1.54 寸 SPI TFT，灰排线 | 文字、状态和图像预览 | 用户确认，有显示证据；具体屏控/料号未读回 | 本板 U7 是 3.3V 10 芯接口；按当前初始化推断兼容性，不能仅按尺寸购买 |
| HW07 | 飞特 STS3215-C001 / 官方 ST-3215-C001 | 带反馈总线舵机、夹爪执行 | 用户至少 1 个；未证明已在线或动作 | 官方列 6–7.4V，独立动力供电；[执行器档案](../02_设备档案/01_电机舵机与驱动.md) |
| HW08 | 标注 TTL-BUS / RS485-BUS 的转接板 | MCU 双线 UART 与舵机总线电气转换、动力接入 | 用户确认；完整型号/原理图待补 | 端口与电源路由未确认，不能把 7.4V 引到 MCU 逻辑 VCC |
| HW09 | WHEELTEC MG310P20_7.4V，F0060299，霍尔版 | 直流减速电机、编码器测速和 PID 学习 | 用户持有，未证明已接入 H743/运行 | 动力额定 7.4V，编码器用 3.3V，两套电源用途不同 |
| HW10 | 电机 H 桥驱动板，尚未选定 | 承受动力电流、PWM 与换向 | 缺少；软件预留多种控制接口 | VM/逻辑/输出要分别核对；不是加一根供电线就能替代 |
| HW11 | EC11 旋钮编码器，具体版本待登记 | 调整目标 RPM；若带开关可控制启停/方向 | 用户已指定；是否接线待验 | 裸机械触点无独立供电，模块版按 3.3V 上拉；每格边沿数待实测 |
| HW12 | 独立按键、板载 LED1/LED22、外接 LED | 输入事件，心跳/故障提示 | 板载灯见原理图；外接器件装配待盘点 | LED1 PG7 低有效；LED22 电源灯；外接 LED 需限流电阻 |
| HW13 | JDY-31 蓝牙串口模块 | 无线传送夹爪命令/反馈 | 用户确认 JDY-31；底板和固件版本待确认 | 经典 SPP；底板供电和 AT 版本仍需核对；[蓝牙档案](../02_设备档案/02_蓝牙JDY与HC08.md) |
| HW14 | HC-08 | 蓝牙替换候选 | 用户提出候选，未确认购入/测试 | 官方 V3.1 核心板为 BLE、2.0–3.6V，推荐 3.3V；底板另核 |
| HW15 | XCAM V1.3 | 摄像头图像检查的辅助工具 | 用户持有；项目未接入 | 未确认端口和供电，不能与 MCU 并联驱动摄像头控制/数据引脚 |
| HW16 | W25Q64JV，板载 8MiB QSPI Flash | 参数/数据实验、存储映射 | 原理图板载，既往读 ID EF4017 | 板上 3.3V；不能换成引脚相似的 1.8V 型号后直接上电 |
| HW17 | TF/SD 卡座与 microSD 卡 | 文件与图像记录 | 卡座板载；是否插卡和卡规格待登记 | 板上 3.3V；历史 SD=0/FS=0 不应登记成可用 |
| HW18 | 25MHz HSE、32.768kHz LSE、RTC 备份域 | 系统时钟、日历、断电保持 | 晶振/备份接口见原理图；外接电池未确认 | VBAT 是专用备份输入，不能当动力/整板电源 |
| HW19 | 备用 PWM 舵机，两路接口 | 兼容脉宽控制执行器 | 软件支持，实物型号/数量未确认 | 不能由 PWM 波形推导舵机供电；按具体舵机规格 |
| HW20 | 外部稳压电源/DC-DC/电池与保护 | 后续脱离 USB 的整机供电 | 规划项，未选型 | 见[预算与上电步骤](../01_供电设计/02_电流预算与上电检查.md) |

软件工具 VOFA、串口助手、IAR 和手机 App 不计入硬件 BOM；它们的协议/平台兼容性仍属于设备替换条件。清单可在[CSV](硬件清单.csv)中筛选维护。引脚继续由[设备引脚矩阵](../../整合交付/02_设备引脚与功能矩阵.md)维护，不在多个文档里各自修改一套。
