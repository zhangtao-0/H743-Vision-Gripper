# 视觉、输入与板载设施档案

## 摄像头 FD5640-500w-V11

作用：提供图像输入。用户已确认该模块，历史固件有画面随目标移动的实物证据；当前输出/裁剪按 240×240 RGB565 预览，并不等于用满传感器标称分辨率，也不代表视觉识别/自动抓取已实现。

本板 FPC1 摄像头接口使用 3.3V 网络，控制走 SCCB、图像走 DCMI 并行数据与同步信号。不能把裸 OV5640 的核心/模拟/I/O 多路供电范围直接当作模块接口 VCC，更不能因另一块模块写“可接 5V”就给当前 FPC 接 5V。FD5640 具体模块原理图和稳压结构仍待补。

换摄像头应核对：连接器间距/位数/触点面及顺序、VCC与各信号电平、片上 ID、SCCB 地址、复位/掉电极性、XCLK 来源、PCLK及同步极性、输出格式、支持尺寸与寄存器表。接口相同也可能需要新初始化表；换 OV2640 需用项目相应配置，并重新测帧缓冲、DMA 长度和图像质量。USB 摄像头或 MIPI 模组不能当作此 DCMI 模组直接插入。

用户持有 XCAM V1.3，可作为诊断工具候选，型号接口手册尚未核对。使用时明确谁负责供电、时钟和 SCCB 控制，先断电切换连接，避免两个主机同时驱动同一模块。

## 1.54 寸 SPI TFT 屏幕

作用：显示启动状态、舵机/电机数据和视觉预览。当前灰排线屏与本板 U7 10 芯接口配合；原理图标 3.3V，信号包含 SCK、MOSI、CS、DC、BL。当前驱动按现有初始化序列与 240×240 显示组织，**屏控芯片的确切料号没有实物标识/读回证据**。

不要仅凭“1.54 寸 SPI”就认为另一屏可直接替换。需查屏控型号、分辨率、SPI 模式/最大频率、像素格式、GRAM 窗口偏移、RGB/BGR、方向、复位方式、背光电流与极性、FPC 针序和触点面。带稳压底板的 5V 屏板与裸 FPC 屏是两种电源入口。换屏通常涉及驱动初始化/显示配置，不应改动应用层每一处绘图调用。

## EC11、按键与 LED

EC11 是用户指定的机械旋钮，用于给目标速度，不是 MG310 电机上的反馈传感器。裸旋钮通常是 A/B/C 触点，公共端接地，输入上拉到 3.3V；带 CLK/DT/SW/VCC 的模块还应核对其电阻网络。模块用 5V 会把上拉电平带到 5V，不能照搬到当前接线。

不同 EC11 版本每格边沿数、定位点与脉冲比例可能不同。先慢转一格记录有效计数，再配置 `MOTOR_KNOB_EDGES_PER_DETENT`；旋向反了可校准 A/B 顺序或映射，不能修改电机 CPR 来修旋钮。

板载 LED1 PG7 低有效，LED22 为电源灯；外接状态灯用 PG0/PG1 配限流电阻。换 LED 依据正向压降与所需亮度算 `R≈(3.3V−Vf)/I`，电流受 MCU 与板级约束；不要让 GPIO 直接驱动灯带、蜂鸣器大负载或功率灯。普通按键无极性，但模块型按键可能含上拉和电平电路。

## 存储、时钟与备份

| 设施 | 当前作用/接口电源 | 替换时最容易漏掉的条件 |
|---|---|---|
| W25Q64JV | 板载 QSPI、3.3V、8MiB | 同脚位芯片可能是 1.8V；容量、JEDEC ID、擦除粒度、QE、地址模式与读指令不同 |
| microSD | 板载 SDMMC 卡座，3.3V | 容量/格式、供电瞬态、速度、连接；没有 SD/FS 成功日志就不登记通过 |
| 25MHz HSE | 当前 PLL 的时钟输入 | 改晶振会影响全部派生时钟，需校核频率/负载/布局 |
| 32.768kHz LSE | RTC 时间基准 | 晶体负载/起振、备份域；不把同频晶体任意替换而不验证 |
| VBAT 备份 | 断开主电后维持 RTC 域 | 电池种类、实际 VBAT 电压、与3.3V的二极管路径；未确认电池型号，不填写随意可用范围 |

这里的 RTC 备份电池不是“主板后备电源”，也不能给主板外设和执行器供电。资料不足时按原理图保持当前连接，不能拿主电池接 VBAT。

## 调试与主机接口

本板 Type-C 直连 MCU 的 PA11/PA12，USB CDC 要有固件枚举才能形成虚拟串口；ST-Link 用 SWD；USB-TTL 经 USART1。三者不能因都有 USB 插头而混用。USB-TTL 的 VCC 电压选择开关，也可能只控制供电输出而不改变 TX 电平，实际应量测/查手册。替换调试器确认 SWD、目标参考电压、驱动和 IAR 支持，且不把调试器电源输出与外部电源直接并联。
