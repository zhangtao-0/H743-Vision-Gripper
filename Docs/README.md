# H743 项目文档

当前工程的功能、构建和验收以 [整合交付](整合交付/README.md) 为准。该版本把 servo 业务与厂商外设接入同一个 H743 工程；P1/P2/P3 不再作为最终覆盖范围。

| 目录 | 用途 |
|---|---|
| [整合交付](整合交付/README.md) | 完整成果、设备矩阵、构建/运行入口、修改记录、测试证据 |
| [官方参考历程](官方参考历程) | 厂商原件；保持不变，适配副本在 project/App/vendor |
| [适配规划](适配规划/README.md) | 最初调查、架构及 P1/P2/P3 历史实施记录；设备 CSV 已同步到整合版 |

优先阅读 [按设备的引脚与功能矩阵](整合交付/02_设备引脚与功能矩阵.md) 和 [编译烧录与验收](整合交付/03_编译烧录与验收.md)。

默认配置用于 FD5640/OV5640，另有 OV2640、关闭摄像头配置。软件构建/主机测试与真实硬件验收分别记录，尚未烧录和执行机械动作。
