# 编译、运行入口与整合验收

## 编译配置

使用 `project/EWARM/H743_VisionGripper.ewp`，IAR Build Utility 9.2.2 / ARM Compiler 9.40.1：

| IAR 配置 | 对应硬件/用途 | HEX |
|---|---|---|
| `H743_VisionGripper` | 默认 FD5640/OV5640 + 全部整合功能 | `project/EWARM/H743_VisionGripper/Exe/H743_VisionGripper.hex` |
| `H743_VisionGripper_OV2640` | 改用 OV2640，其他系统相同 | `project/EWARM/H743_VisionGripper_OV2640/Exe/H743_VisionGripper.hex` |
| `H743_VisionGripper_NoCamera` | 关闭摄像头启动/采集，其他模块保留 | `project/EWARM/H743_VisionGripper_NoCamera/Exe/H743_VisionGripper.hex` |

可在 H743 目录运行 `./Tools/build_integrated.ps1 -Clean` 重建全部配置。当前默认版面向用户实际 FD5640 模块，不能把 OV2640 配置用于 FD5640。

## 启动时应观察到的现象

HOST=115200/8N1，出现 `integrated-v1` 启动标识和厂商设备识别信息。部分设备初始化需要时间；缺 SD 卡或摄像头识别失败应报告对应状态，不应阻止后续模块调度。

初始化完成后：PG7 启动短闪并心跳；LCD 显示系统文字；摄像头成功时开始快照/分条预览。STS 先按 1 Mbps、ID=0 探测，失败后按原 P3 速率候选尝试；只修改 MCU UART，不修改舵机 EEPROM。识别完成后进入原命令/控制层，按键/主机帧才触发动作。

摄像头初始化或捕获错误也会触发 PG1 故障闪烁；捕获错误计数为累计诊断值，复位后清除。

KEY3 单击切换预览，KEY4 单击打印设备状态。`BOARD_KEYS34_CONTROL_PWM=1` 时二者改为原 PWM 按键，预览/状态改用控制台命令。

## UART 或 USB 控制台

输入命令时以 `@` 开头，以回车或换行结束。例如串口助手发送 `@status\r\n`，其中 `\r\n` 应为实际行尾，不能是四个文字字符。

| 命令 | 行为与预期 |
|---|---|
| `@help` / `@status` | 列命令；显示 clocks/LCDbus/RTC/SD/FS/QSPI/USB、帧数、超时、主循环最大间隔和队列丢弃 |
| `@camera off` / `on` / `retry` | 暂停、恢复或重新初始化；无传感器时 ready=0 |
| `@lcd test` | 暂停预览，画 RGB 色块和文字；用 `@camera on` 回预览 |
| `@rtc` | 打印 RTC 时间；首次默认值不是当前实时时钟 |
| `@rtc set 2026 10 21 12 30 0` | 设置并验证日历；仅为输入示例，改成真实时间 |
| `@sd retry` / `@sd read` | 重挂卡；读原始 sector 0，不写卡 |
| `@sd filetest` | 新建 H743TEST.TXT、写入/同步/关闭/重新读取比较；同名已存在则返回 BUSY，保留原文件 |
| `@qspi test` | **擦除外部 W25Q64 最后 4 KB（0x7FF000），写 32 字节并读回比较**；该扇区应作为专用测试区 |
| `@qspi map` / `unmap` | 进入/退出映射；进入前后比较前 16 字节，MPU 限制为只读不可执行 |
| `@pwm 1500` / `@pwm2 1500` | 显式启动 PWM1/2，脉宽范围 500–2500 µs |
| `@pwm angle 0 90` | 原 PWM 角度接口，舵机编号 0/1，角度 0–180 |
| `@pwm off` | 关闭两路 PWM 输出 |
| `@af` | OV5640 自动对焦固件下载和连续对焦；仅适用于兼容 AF 模块 |
| `@stream on` / `off` | 10 Hz CSV 遥测开关 |

CSV 每行 9 列：`tick_ms,position,angle_tenths,voltage_mV,current_mA,load,online,moving,camera_frames`。按这些字段配置 VOFA 的文本数据解析；未自动创建 VOFA 面板。原有官方/扩展二进制帧仍保留；使用纯 CSV 绘图时避免同时发送会产生二进制回复的指令，或使用支持混合数据分流的自定义解析器。

USB CDC 现在会处理接收数据；普通非命令输入回显。Type-C 必须是数据线。未枚举时不会等待电脑或覆盖正在传输的缓冲。SD/QSPI 写测试、重新初始化、AF 和 LCD 测试会在 STS 反馈或控制状态仍在运动时返回 BUSY，避免长操作拖延控制任务。

现场调试新增：`@servo probe ID BAUD` 为只读、离线阶段专用查询；非配置 ID 识别成功不会启用运动。`@camera clock 4` 使用已测试的约 40 MHz DVP；`@camera clock 0` 回到原厂商自动配置（仅用于排查）。`@status` 新增原始 RX、格式/时钟读回、DCMI/DMA 错误及超时 NDTR。
