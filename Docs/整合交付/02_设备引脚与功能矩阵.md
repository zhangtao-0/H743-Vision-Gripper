# 按设备的最终引脚与功能矩阵

> 当前接线入口：[引脚与接线主档](../引脚与接线/README.md)。包含完整板序表、设备接线和空闲清单；本页保留整合阶段记录。

板卡：芯路城鹿小班 LXB743ZI-P1 / STM32H743ZIT6。完整逐信号 CSV：[设备引脚分配](../适配规划/03_硬件规划/设备引脚分配.csv)；全部 108 个 GPIO 引出：[板级引出与用途表](../适配规划/03_硬件规划/板级引出与用途表.csv)。

本轮重点变更：PWM 从原 PA6/PB1 迁到 PD12/PD13，确保 PA6 的摄像头像素时钟不会被覆盖。原理图 U9-59/60 已核对；TIM4_CH1/CH2 的 AF2 依据 [ST STM32H743 数据手册](https://www.st.com/resource/en/datasheet/stm32h743bg.pdf) 的复用表。
