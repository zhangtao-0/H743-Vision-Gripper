# H743 完整功能整合版

## 新增学习入口（2026-10-22）

[项目教学手册](../教学手册/README.md)。本入口链接到本次维护的学习与项目资料；下方历史索引未做全库重整。

当前目标是同一份 H743 工程运行 servo 业务和厂商外设功能。此前 P1/P2/P3 是历史阶段，不能再用“完成舵机只读探测”代表整个项目完成。

**软件整合已接入：STS、原夹爪命令/控制、VOFA、蓝牙、两路 PWM、按键、LED、SPI LCD、OV5640 预览、可选 OV2640、RTC、SD/FatFs、QSPI 读写/映射、USB CDC，以及 H7 限位持久化。** 默认、OV2640、关闭摄像头三个 IAR 配置均通过编译链接；板上功能验收尚未执行。

主工程：`../../project/EWARM/H743_VisionGripper.ewp`。默认配置 `H743_VisionGripper` 面向用户的 FD5640 模块；正常流程为初始化外设 → 探测 STS → 接入原业务 → 在同一循环中调度摄像头/显示/按键/通信。

当前没有上电自动夹取或自动启动 PWM。原有按键/帧命令仍是动作入口。摄像头当前实现的是采集与预览，尚未加入目标识别、机械臂标定或自主抓取算法。
