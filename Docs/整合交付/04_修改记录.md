## 新增与接入

- `App/vendor/lcd/camera/sd/qspi`：当前工程的厂商驱动适配副本，保留原声明。
- `Middlewares/FatFs`、USB Device Core/CDC、`USB_DEVICE`：提取厂商文件系统和 USB 中间件，不复制其 HAL。
- `board_peripherals.*`：共享外设时钟、RTC、MPU 和两路 H7 PWM。
- `board_devices.h`：按设备集中 LCD、DCMI、SCCB、SD、QSPI、PWM 的引脚与复用。
- `board_camera.*`：AXI SRAM 专用缓冲、快照采集、DMA/帧双完成检查、超时恢复、4 行刷新。
- `board_storage.*`：SD/FatFs 适配、重新挂载、文件测试、QSPI QE/映射/读写测试。
- `usb_console.*`：USB 接收回显、独立 ISR/主循环队列、发送缓冲生命周期。
- `claw_limit_storage_h7.c`：替代 RAM 后端；内部 Flash 双扇区记录、版本/序号/CRC、损坏回退。
- `integration_service/console/vendor_log`：全部模块的初始化、协作调度、状态与控制台、CSV 遥测。
- EWP：加入当前 HAL SPI/DCMI/SD/QSPI/RTC/PCD/LL 驱动，增加 OV2640 和关闭摄像头配置。

## 纠错与原因

| 原问题 | 修正 |
|---|---|
| 旧 LCD 复制了私有 HAL SPI 状态/寄存器操作 | 改为调用当前 HAL_SPI_Transmit，并限制单批传输，减少 SDK 耦合 |
| LCD 示例按原时钟设高速 SPI | 当前 SPI6 kernel=100 MHz，4 分频到 25 MHz |
| SCCB 多个函数最后无条件返回 SUCCESS | 保留 ACK 失败、停止总线并计数；传感器初始化遇到 SCCB 错误不报告 ready |
| SCCB/Camera 使用与编译优化有关的空循环延时 | SCCB 使用当前 CPU 周期计数，传感器毫秒等待使用 HAL_Delay |
| 示例连续 DMA 和 CPU 同时操作同一图像缓冲 | 改为快照采集完成后再显示，显示结束再开始下一帧 |
| 帧回调不代表 DMA 已完成 | 同时检查帧标志与 DMA READY，错误或超时停止并重试 |
| Camera 缓冲地址未被链接脚本保护 | `.camera_dma` 固定进入 AXI SRAM，32 字节对齐、非缓存、不可执行 |
| SD 反初始化释放 GPIOB8/9、PC6/7 | 移除非 SD 所有引脚，避免破坏摄像头和扩展资源 |
| SD 擦除末地址计算超出一块 | 末块改为 BlockIdx + BlocksNbr - 1 |
| FatFs 原分发未检查 drive/缓冲/扇区范围 | 改为单 SD 端口；边界检查；对齐的 512 字节中转缓冲 |
| SD 写忙和 QSPI 擦除可能超过短 I/O 超时 | SD 读写/写忙等待放宽至 1 秒，QSPI ready 轮询保留 5 秒预算，普通命令仍有短超时；操作仅在维护阶段执行 |
| QSPI 命令结构未完整初始化，映射函数复位芯片 | 清零结构；进入映射前不再复位，避免清除挥发性 QE |
| QSPI 四线操作未确认 QE；MPU 默认禁止 0x90000000 | 校验/设置挥发性 QE；建立只读 MPU 窗口；映射前后比较数据 |
| USB 等待枚举、空 pClassData 解引用、覆盖忙 TX 缓冲 | 删除等待；空指针/配置状态检查；保留端点缓冲直到完成；RX 真正接入控制台 |
| 旧 PWM 占用摄像头 PA6，且原 PWM 模块未调度 | 两路改为 TIM4 PD12/PD13，旧 API 通过桥接调用 H7 后端；接回原虚拟按键 |
| P3 部分探测响应只检查宽松最小长度 | 按 PING/ID/MODEL/BAUD/LIMITS 检查精确包长，并拒绝设备错误响应 |
| 长维护操作可能拖延运动任务 | 运动反馈或控制状态忙时拒绝 SD/QSPI/AF/重新初始化等维护命令 |
| 旧限位 Flash 页地址和 RAM 后端不满足 H7 持久化 | ROM 截止 0x081BFFFF，Bank2 sector6/7 专用；不在启动时擦写；Bank-swap 时拒绝擦除 |
| MPU 和新增 IRQ 放在易被生成器覆盖的位置 | 内存配置移到 board 层，在 USER Init 调用；新增 IRQ 保存在 USER CODE 区 |
| 既有未调用私有 HoldFeedbackPosition 产生 Pe177 | 确认仅声明/定义、无调用后删除该死函数，保留其他停止保持逻辑 |

旧 UART 对应关系保持：STS=USART2 1 Mbps，HOST=USART1 115200，蓝牙=USART3 9600；原仓库的 9600 属于旧蓝牙。不会为了迁移更改舵机 ID、EEPROM 波特率或自动执行标定。
