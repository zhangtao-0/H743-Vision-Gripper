U9/U10总表完整列出120个接点（包含电源、地、参考和VBAT），H1另列8个；不是只列已经用的脚。空闲候选、源码已分配、板载连接、条件预留和实物已接线是不同概念。

## 两个最容易接错的地方

- U9-1/2=3.3V，U9-3/4=5V，U9-13/14=GND。
- **U10-1/2/3/4全部是GND**；H1-3=GND，H1-4=5V。不能把U9供电顺序套到U10。

所有编号按原理图连接器Pin1定位，不按照片旋转方向猜。原理图见[U9/U10截图](证据/U9_U10原理图排针.png)、[U10顶部放大](证据/U10顶部供电核对.png)。本轮核对原理图和源码，没有新接线、烧录或实物通断测试。

本表针对默认FD5640、菜单开启、TB6612 profile2的当前工程；关闭某个编译功能不会使板上已焊接的负载自动消失。器件供电与替换另查[硬件档案](../硬件档案/README.md)。返回[项目根目录入口](../../README.md)。
