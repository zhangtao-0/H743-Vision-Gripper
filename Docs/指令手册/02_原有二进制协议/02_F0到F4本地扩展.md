# F0–F4：STM32 本地管理命令

发送位置：HOST USART1，或蓝牙RAW通道；原STS命令栈启动后处理。规范使用ID=`FE`，外形仍是`FF FF FE Len F? Params CS`，普通校验规则适用。这些指令在MCU本地处理，不直接交给舵机解释。

## F0 打印 / F1 示例 / F3兼容

| 功能 | HEX | 作用 |
|---|---|---|
| F0关闭周期打印 | `FF FF FE 03 F0 00 0E` | 关闭claw打印，不停运动 |
| F0开启周期打印 | `FF FF FE 03 F0 01 0D` | 记录本次来源，按claw打印周期输出 |
| F0单次打印 | `FF FF FE 03 F0 02 0C` | 一次，不改周期开关 |
| F1打印示例 | `FF FF FE 02 F1 0E` | 现有固件内置示例文本；其中旧位置模式示例校验偏差见修订记录 |
| F3兼容占位 | `FF FF FE 03 F3 00 0B` | 只回复最新运动命令自动生效，不切控制权、不解锁 |

F0的`claw:位置,目标角度,电压mV,电流mA`与`@stream`的9列CSV不同。`@stream off`不能关闭F0，F0关闭也不能关闭P3诊断。新运动命令覆盖旧目标的规则属于动作逻辑，不是F3颁发权限。

## F2 参数管理

| 动作 | Params布局 | 示例HEX |
|---|---|---|
| 列表 | `00` | `FF FF FE 03 F2 00 0C` |
| 查询 | `01 ID` | OPEN_SPEED ID4：`FF FF FE 04 F2 01 04 06` |
| 设置16位 | `02 ID ValueLE16` | OPEN_SPEED=900：`FF FF FE 06 F2 02 04 84 03 7C` |
| 设置32位 | `02 ID ValueLE32` | 同值：`FF FF FE 08 F2 02 04 84 03 00 00 7A` |
| 恢复一个 | `03 ID` | ID4：`FF FF FE 04 F2 03 04 04` |
| 恢复全部 | `04` | `FF FF FE 03 F2 04 08` |

设置值解释为有符号16位或32位小端整数，不能塞入F5浮点编码。当前SetParam按范围裁剪；查询确认实际保存到RAM的值，不能把“收到回复”理解为原值原样接受。列表当前输出“参数中文名：当前值”，并没有像旧表文字说的那样逐行打印默认/范围。

参数ID、单位和持久化见[当前参数表](04_参数ID与持久化.md)。F2恢复全部是运行参数恢复，不是舵机EEPROM恢复，也不等于清除已保存机械极限。

## F4 机械极限与标定

| action | HEX | 效果 |
|---|---|---|
| 0查询 | `FF FF FE 03 F4 00 0A` | 查询标定/极限/动作范围，不写Flash |
| 3开始 | `FF FF FE 03 F4 03 07` | 进入标定，后续A0/B0记录与扫描行为随模式改变 |
| 4取消 | `FF FF FE 03 F4 04 06` | 取消本轮临时打点，保留旧记录 |
| 5清除 | `FF FF FE 03 F4 05 05` | 清除已存机械极限，涉及内部Flash记录 |
| 6完成 | `FF FF FE 03 F4 06 04` | 校验两端及跨度，成功才保存并退出 |

F4还返回11字节二进制ACK：`FF FF FE 07 F4 action status setting valid range CS`。status按HAL值，setting/valid为标志，range表示所选范围；同时可能有中文文本。ACK与请求长度不同，不要用“收到同一11字节就按F5解析”的规则。

规范流程是查询 → 明确要标定后开始 → 在标定模式记录闭合/张开端 → 完成保存；需放弃时取消。清除不是取消，没有新机械确认时不把任意0/270度当安全端点。F4不是屏幕菜单协议，后续菜单操作文档另行设计。
