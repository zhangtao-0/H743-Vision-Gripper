# `@` 文本指令完整表

这里的AT指 `@` 前缀，并非 JDY/HC 模块的 `AT+...`。入口为USART1或USB CDC，大小写按表输入，每次一行后回车。依据[Execute与行解析](../../../project/App/modules/integration/integration_console.c)，以实际分支为准，`@help`不是完整协议定义。

## 系统与视觉

| 指令 | 参数/示例 | 作用与回复 | 状态/副作用 |
|---|---|---|---|
| `@help` | 无 | 打印主要命令 | 当前为9类可复制帮助，具体示例随目录生成 |
| `@status` | 无 | STS、SYS、CAM诊断与MOTOR状态 | 只查询，不使设备在线、不启动动作 |
| `@stream on` | 无 | 开启约100ms一次的9列CSV | 不打印专门确认；输出到HOST和USB |
| `@stream off` | 无 | 关闭上述CSV | 不关闭P3日志或F0 claw打印 |
| `@rtc` | 无 | 当前日期时间/不可用信息 | 不设时间 |
| `@rtc set Y M D h m s` | `@rtc set 2026 10 22 15 30 0` | `RTC set=0`表示HAL_OK | 2000–2099、真实日期、0–23/59/59；修改RTC备份域 |
| `@camera off` | 无 | 停止采集/显示状态 | 通常无直接确认，可查status |
| `@camera on` | 无 | ready时使能预览 | ready=0时不会仅凭命令修复；查status |
| `@camera retry` | 无 | 停止并重新初始化摄像头，打印HAL状态 | 不保证已恢复显示，应查enabled再on |
| `@camera clock N` | `@camera clock 4` | 修改OV5640 PCLK配置并读回，打印HAL状态 | 实际支持0/1/2/4/8/16；0=传感器自动，1等未实测值不作推荐；不是SPI时钟 |
| `@lcd test` | 无 | 关闭预览，绘制RGB色块和文字 | 不代表恢复预览；后续需camera on |
| `@af` | 无 | OV5640 AF固件下载/连续对焦触发，打印HAL状态 | 仅5640配置有分支；成功后会重新使能预览 |

`@stream` CSV顺序：`tick_ms,position,angle10,voltage_mv,current_ma,load,online,moving,camera_frames`。angle10为角度×10；它不是MG310转速流，也不是VOFA二进制浮点包。其他日志仍可能夹杂，PC解析器应识别行格式。

## MG310 电机

| 指令 | 参数/示例 | 作用与判读 |
|---|---|---|
| `@motor status` | 无 | 报告ready、driver、on、fault、dir、target、rpm10、pwm、cpr1000、count、blocked、invalid |
| `@motor enable` | 无 | 使能请求，`enable=1`才接受；driver/ready/CPR/fault条件会拒绝。默认无H桥profile0拒绝启动 |
| `@motor stop` | 无 | 禁能、目标清零、控制器复位、输出归零；不清除已有fault，不停STS |
| `@motor reverse` | 无 | 翻转请求方向；启用后经换向状态机等待低速再反转；不自动使能 |
| `@motor clear` | 无 | 停止并清除故障，不自动重新启动；先排除故障原因 |
| `@motor zero` | 无 | 停止状态且ready时清累计计数，返回1成功；不是硬件定时器和滤波状态的全面复位 |
| `@motor rpm N` | `@motor rpm 100` | 非负整数RPM，默认0–400；超出控制器max拒绝，target=1表示接受，不是“目标=1RPM” |
| `@motor cpr N` | `@motor cpr 1061` | 停止状态设置整数counts/rev，1–1000000；不能用1061268代替小数1061.268 |
| `@motor pid KP KI KD` | `@motor pid 1800 5000 0` | 停止状态，每项0–100000，输入为真实增益×1000；示例等于1.8/5/0 |

`rpm10`是有符号实测RPM×10；`cpr1000`是当前浮点CPR×1000的报告值，**设置命令却接收整数CPR**。要保留默认1061.268精度，使用编译配置，不发送把报告值直接写回的命令。这些文本命令仅改RAM；UI版可随后在默认参数页SAVE支持的开机配置，没有新增文本保存别名。

## 存储与 PWM

| 指令 | 参数/示例 | 作用与副作用 |
|---|---|---|
| `@sd retry` | 无 | 重新初始化并挂载；`SD mount=0`表示HAL_OK，不是卡不存在 |
| `@sd read` | 无 | 读sector0一块；不格式化、不写卡 |
| `@sd filetest` | 无 | 新建/写入/回读`0:/H743TEST.TXT`；已有文件返回HAL_BUSY并保留，不覆盖、不自动删除 |
| `@qspi test` | 无 | **擦除外部Flash最后4KiB扇区0x7FF000并写入32字节测试图案**，会取消映射；不是无损读取 |
| `@qspi map` | 无 | 验证并启用0x90000000只读内存映射，影响QSPI访问模式 |
| `@qspi unmap` | 无 | 退出内存映射；依赖该映射的使用者应先停止 |
| `@pwm US` | `@pwm 1500` | PWM1 PD12，接受500–2500µs；可能使所接PWM舵机动作 |
| `@pwm2 US` | `@pwm2 1500` | PWM2 PD13，同范围；不是USART2舵机 |
| `@pwm angle CH DEG` | `@pwm angle 0 90` | CH=0/1，整数0–180°，经过PWM控制层映射 |
| `@pwm off` | 无 | 停止两路PWM输出；不等于STS卸力或MG310停止 |

HAL数值通常0=OK、1=ERROR、2=BUSY、3=TIMEOUT；`accepted=1`/`motor pid=1`等是布尔成功值，不能混用。模块ready和实际功能仍须另看状态/物理反馈。

## STS只读探测

`@servo probe ID BAUD`，如 `@servo probe 0 1000000`。ID范围0–253，波特率9600–1000000且UART需能实际配置，P3已ONLINE时拒绝。`accepted=1`是接受重新探测，不是舵机已应答。随后查STS rawRx/valid/target/rate与P3状态。它不是改舵机ID或EEPROM波特率的指令。

## 维护限制与输入规则

SD各项、QSPI各项、camera retry/clock、af、lcd test、rtc set属于当前维护拦截集合；检测STS moving、控制层运动或MG310 enabled时可能返回`BUSY: stop motion before maintenance command`。这套拦截不是针对所有动作命令的全局互锁，不覆盖所有PWM实际运动。

行缓冲96字节，`@`之后最多95个可打印ASCII字符；待处理行每通道仅一个邮箱。未完成行相邻字节间隔超过200ms会丢弃，故不建议在字符直发终端慢慢逐字输入；在输入框编辑好整行再发送。过长/非ASCII/邮箱忙会计入cmdDrop。

当前sscanf数字分支可能接受尾随字符，部分无效参数最终只显示unknown command，且unsigned解析不是严格语法校验。按本表发送完整十进制参数，不依赖宽松解析、负数绕回或省略字段。未回消息可能是正常无确认分支，也可能指令被丢弃；用status和计数判断。

## UI版的显示与持久化补充

[屏幕UI版](../../屏幕交互/README.md)中，`@camera on`开启采集并解除LCD测试占用，仅在CAMERA观测子页预览；`@lcd test`后任一菜单手势先恢复菜单，不执行该手势的其它业务。F2参数和`@motor`仍先改RAM，随后可用菜单SAVE保存支持字段；机械端点不被开机配置覆盖。

## MG310专用VOFA波形（20261023-motor-vofa-v1）

| 命令 | 行为 |
|---|---|
| `@motor plot on` | 主动开启HOST专用8通道JustFloat，名义50Hz；不启动电机，旧TX未排空时拒绝，稍后重试 |
| `@motor plot off` | 停止曲线并恢复HOST文字；不停止电机 |
| `@motor plot status` | 查询曲线开关、发送/丢包；曲线期间文字从USB查看 |
| `@motor disable` | 正常禁能并保留目标RPM；区别于清零目标的@motor stop |

KEY7当前点按启停、长按1秒换向；模拟为`@key 7 tap`和`@key 7 press 1200`。默认目标400，上电仍禁用。曲线启用后HOST回复独占JustFloat，旧二进制应答会被拒绝以免污染波形，原有输入格式不改；关闭后恢复。实体模块/接线、波形通道和PID实操见[电机VOFA教程](../../电机控制/04_VOFA旋钮按键与PID曲线.md)；TB6612接线见[H桥制作教程](../../电机控制/05_H桥原理制作与TB6612接线.md)。
