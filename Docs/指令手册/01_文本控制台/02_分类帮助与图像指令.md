# 分类帮助、静默与图像操作指令

input-map-v1已将帮助扩为9类、按25ms发送可执行命令集合；新增按键/调参接口见[当前补充](03_按键模拟与共享调参.md)。下文保留v2背景。

版本screen-ui-v2，2026-10-22。以下`@`命令用于USART1/115200或USB CDC，行尾回车/换行。JDY-31仍使用原二进制业务，没有增加`@`解析。主动查询/帮助仍返回文字；“默认静默”指不自动周期发送或打印上电日志。

| 指令 | 行为 |
|---|---|
| `@quiet` | 停止P3周期遥测、CSV流、夹爪周期打印，取消尚未发完的分类帮助；不停止电机/舵机/相机，不屏蔽主动查询 |
| `@telemetry on` / `@telemetry off` | 显式开关P3只读探测阶段的状态遥测；运动栈接管后该状态机不再运行，因此不是所有阶段的统一遥测入口 |
| `@help` | 打印分类编号，屏幕“指令帮助”提供相同分类入口 |
| `@help N` | N=0系统/静默，1夹爪，2电机，3相机/图像，4PWM，5存储/时钟，6二进制协议；逐循环一行，重复请求未结束会BUSY |
| `@camera shot` | 请求下一完整帧留在RAM并冻结；返回受理情况，观察STILL/帧数确认实际完成；未写SD文件 |
| `@camera live` | 解冻并开启连续采集；仅图像查看页显示 |
| `@camera rotate` | 显示图像顺时针+90°，四次回到0° |
| `@camera mirror` | 切换图像左右镜像 |
| `@camera flip` | 切换图像上下翻转 |
| `@camera edge on` / `@camera edge off` | 显示黑白梯度边缘/恢复RGB；不执行直线拟合或抓取 |
| `@lcd rotate` | 屏幕文字与逻辑坐标+90°；图像自身方向保持独立配置 |

`@stream on/off`仍控制CSV，F0或CLAW_PRINT参数可手动启用夹爪打印。默认值均关闭；即使旧开机配置保存了CLAW_PRINT=1，加载时也强制关闭该开关，防止重新刷屏。

方向变更只是当前RAM设置，进入默认参数→SAVE并确认可作为下次开机方向。冻结画面、边缘预览和自动打印启用状态不自动保存为开机行为。

现有`@camera on/off/retry/clock`、`@lcd test`、`@motor...`等保持原接口，完整命令见[原文本表](01_完整AT指令表.md)。屏幕动作直接调用业务API，不向本机串口发送指令字符串。自动夹取没有可执行的新增串口命令。
