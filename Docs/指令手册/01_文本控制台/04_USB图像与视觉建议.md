# USB图像与二维视觉建议指令

版本20261023-pc-vision-v1。图像只从USB CDC发出，USART1仍可使用原FF二进制帧与@文本。两者是不同COM端口；每个端口由一个电脑程序占用。

| 指令 | 作用 | 范围与副作用 |
|---|---|---|
| `@video on` | 开启USB图像帧 | 相机/USB功能可用才受理；不代替camera live |
| `@video off` | 停止图像传输并清空建议 | 不停止其他运动 |
| `@video fps N` | 设置帧率上限，例`@video fps 2` | N严格整数1–5；仅RAM，不保证实际帧率 |
| `@video status` | 查询发送/终止/阶段/USB及建议状态 | 主动查询时才输出 |
| `@vision status` | 查询同一视频和建议状态 | 无运动 |
| `@vision clear` | 清空建议 | 不是硬件急停 |
| `@vision target SEQ U V ANGLE10 WIDTH SCORE` | 电脑回传候选，通常自动构造 | 严格6个整数；原图序号、u/v、角度十分之一、像素宽、千分比分数 |

抓取建议只在最新完成发送的帧、采集至接收不超过1500ms、USB/相机/视频有效时受理；不执行器械动作。USB成功建议不周期打印到USART1；USB拒绝回复仅回USB。人工从USART1发送则按原日志回复。

`@quiet`仍关闭原有周期文字/CSV，不关闭显式开启的视频；要停图发video off。camera retry会先关闭视频再初始化，需要重新video on。分类帮助可用`@help camera`打印可复制命令。
