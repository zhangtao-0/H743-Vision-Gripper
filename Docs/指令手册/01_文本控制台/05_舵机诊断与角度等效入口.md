# 舵机身份、只读诊断与等效角度命令

## 先纠正ID

原servo仓库提交aebb357dd4096350ec17f49fdaf23d1b27decb3d的[feetech_sts_bus.h](https://github.com/zhangtao-labs/servo/blob/aebb357dd4096350ec17f49fdaf23d1b27decb3d/Project/code/feetech_sts_bus.h)定义默认ID=1、广播ID=0xFE（254）；[usart.c](https://github.com/zhangtao-labs/servo/blob/aebb357dd4096350ec17f49fdaf23d1b27decb3d/Project/code/usart.c)配置USART2为1,000,000bps。ID0是普通单播ID，不是广播。本次将H743默认目标从0改回1，并统一到board_config.h；不写舵机EEPROM改变其实际ID。

本地F5帧中FE是H743本地协议地址，不能据此认为舵机ID0是广播。广播一般不能用于等待单个舵机回包。

## 文本入口

| 命令 | 用途及范围 |
|---|---|
| `@servo status` | 查询目标ID、探测ID、在线/业务就绪、波特率、扫描、原始RX与有效包等计数 |
| `@servo probe ID BAUD` | 指定ID0～253和9600～1000000bps进行只读探测；例：`@servo probe 1 1000000` |
| `@servo scan BAUD` | 固定波特率依次单播PING ID0～253；例：`@servo scan 1000000`；没有任何候选包约25.4秒后停止；若有PING回显还需身份READ确认，耗时会增加 |
| `@servo angle DEG` | 整数0～270度；例：`@servo angle 90`；要求舵机在线、无错误和业务就绪，仍受实际限位/所有权门控 |

角度入口调用与原控制相同的业务层，并非直接写PWM。accepted=1表示业务接受请求，不表示物理动作已完成。扫描不是自动更改目标ID；找到其他ID后，应核对接线与身份，再修改集中配置并重新构建，不将未知设备自动纳入运动控制。

已有运动业务就绪时会拒绝重新扫描/探测，以免在线改UART。扫描不写ID/波特率/位置/扭矩寄存器，不自动夹取。`@help claw`向上位机打印本分类示例。

## 烧录前历史结果与待核对项

旧固件上ID1/1Mbps只读探测没有增加原始接收字节，有效包仍为0。修改目标ID能纠正软件配置，当时还没有证据证明电气链路恢复，也没有H743舵机运动验证。

用户确认转接板V1输入11.5V、没有TTL/RS485拨码或跳帽；这是转接板输入电压，不能在未知板内电路时等同舵机输出端电压。旧F103曾可用说明应优先对照原接法；仍需确认板型、TTL单线BUS接到哪组端子、舵机口实际电压，以及UART是否同地。本转接板用户确认原用同名丝印连接：PA2 TX→板TX、PA3 RX→板RX。此丝印按MCU侧命名，不套用其他转接器的交叉接法。

STS3215-C001已有资料注明6～7.4V；不能因为曾经没坏就把未知的11.5V输出认定为额定安全。请先测量舵机端，再根据实际型号的资料确认。不要带电反插MOTOR/BUS接口，也不要将RS485差分端当TTL端使用。

旧FF FF开头命令继续保留，详见[二进制协议](../README.md)。

## 新增现场证据与修复

厂商软件USB直连显示ID1/1Mbps、STS3215、10.3V，用户确认可运动；状态栏出现“过压欠压”，不把能动作当作额定电压确认。交叉接线的ID1探测无新增RX；恢复同名接线后3次PING新增18字节，但旧固件有效包仍为0。

代码确认存在两处问题：与发送完全相同的PING包被当回显丢弃（ERROR=1时真实状态包也恰好相同）；P3把非零ERROR当格式错误。修复为保留歧义PING候选、用后续READ ID/型号/波特率/限位验证身份，错误位作为设备状态保留。纯回显不能通过身份读取，不能建立最终在线或启动控制；非零错误也不会自动进入运动栈。主机回归通过，是否实物验证以交付记录为准。

## 当前烧录后结果

用户调整舵机最大电压检测阈值、恢复ST-Link后，本版已烧录并独立读回核验。实测ID1/1Mbps、online=1、stack=1、error=0、探测超时与解析错误均0；连续读取位置425、电压10.2～10.3V。没有发送运动命令。具体证据和未验收项目见[实物验收](../../整合交付/20261023_六键菜单与舵机图像排查/烧录后实物验收.md)。调整检测阈值不改变硬件额定电压；没有复现告警状态做单一变量对照，不把任何一项修正说成唯一根因。
