# 按键模拟、共享参数与可执行帮助

本页对应20261023-sixkey-v1，KEY1～4为菜单、KEY5/6舵机、KEY7电机按压；使用ASCII文本并补CRLF，HOST115200和USB CDC可用，JDY-31不支持这些新增文本命令。

| 命令模板 | 可发送示例与说明 |
|---|---|
| `@help GROUP` | `@help keys`、`@help params`、`@help motor`分别查询；也接受数字0..8。`@help`打印9条可复制的分类请求 |
| `@input status` | 查询当前模式、UART/USB模拟掩码、KEY1..6有效状态 |
| `@input mode MODE` | `@input mode mixed`或physical、remote；停运动且所有键释放后切换；RAM设置 |
| `@key ID ACTION [MS]` | `@key 3 tap`、`@key 3 hold`、`@key 3 down`、`@key 3 up`、`@key 3 press 700`分别发送；ID1..7 |
| `@keys MASK MS` | `@keys 12 100`表示KEY3+4同时按100ms；mask1..127，持续40..5000ms |
| `@keys release` | 松开当前文本来源的所有模拟键，不会释放另一来源或GPIO，也不是急停 |
| `@knob STEPS` | `@knob 1`或`@knob -1`，范围-80..80且非0；每格±5RPM |
| `@param list` | 分批打印25个参数的实际值、范围、状态和可复制命令 |
| `@param get ID` | `@param get 21`；ID0..24 |
| `@param set ID VALUE` | `@param set 21 100`设电机目标；ID0/1只读，其余复用屏幕在线/忙/范围检查 |
| `@profile save` | 保存自定义开机参数，仍需停机与维护门控 |
| `@profile load` | 加载，不自动使能 |
| `@profile clear` | 删除开机参数记录，机械极限独立保留 |
| `@claw open` | 张开/松开，复用屏幕动作的业务检查，来源标为HOST或USB |
| `@claw close` | 闭合/夹取，同上 |
| `@claw stop` | 请求停止，可能因反馈无效失败，不是硬件断动力 |

通用tap固定100ms、hold固定900ms，定长press为40..5000ms；down最多保持5秒，可重发down续期。KEY5的约3秒行程选择应使用`@key 5 press 3500`，不能把900ms当作3秒。双击要发送两个分开的tap，先等第一次100ms释放，再在多击窗口内第二次发送。

帮助按25ms最多一行向HOST/USB发送。文本示例给完整数字，不再把on/off/N/CH写成可执行行；`#`说明行不发送执行。HEX示例需按HEX发送字节，文本示例需按ASCII加换行。`@quiet`可以取消未发出的帮助/参数列表。

映射入口：[物理/模拟操作与CSV表](../../输入映射/README.md)、[按键表](../../输入映射/按键映射.csv)、[参数表](../../输入映射/参数映射.csv)、[VOFA快捷指令表](../../输入映射/VOFA快捷指令.csv)。这些是配置依据，尚未导入或实测你的VOFA界面。

原F2/F3的参数范围仍是STS ID0..20；文本/UI追加的21..24是本机电机参数，不改变旧帧枚举。physical模式只禁止模拟按钮/旋钮，不禁止直接控制与参数命令。GPIO、文本和原F5的具体混合关系见映射入口。
