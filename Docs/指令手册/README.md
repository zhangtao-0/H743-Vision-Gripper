## 第一次使用

在 **USART1/USB-TTL 115200 8N1** 或已枚举的 **USB CDC** 以文本方式发送 `@help` 后回车，再发送 `@status`。不要将字符串 `FF FF ...` 当成实际二进制帧。蓝牙当前 USART3/9600 处理二进制业务，**没有接入 `@` 文本解析**。

原二进制指令并未被 `@` 取代；F0–F5/官方帧在当前 H743 里还受 STS 在线后才启动原命令栈的条件影响。设备未在线时不要排队发送运动帧等待它突然执行。[分层页](00_总览/01_入口与分层.md)解释此条件。

后续屏幕UI版已实现翻页、确认/取消和快捷观测，操作规则见[屏幕交互手册](../屏幕交互/README.md)；它不占用新的F5编号，本册仍专门记录串口协议。返回[项目教学手册](../教学手册/README.md)、[项目卡片](../../../../00_项目库导览/01_H743项目卡片.md)。

## 复用按键授权（20261023-debug-grants-v1，未烧录）

`@debug status`查看授权；`@debug <sts|motor> <on|off>`为语法说明，实际发送例子为`@debug sts on`、`@debug motor on`、`@debug sts off`、`@debug motor off`。两个开关可同时ON，上电OFF，退出菜单保留，关闭授权不会停止已有运动。所有共享按键释放后才可修改；旧F5/蓝牙A/B手势同样受STS授权。直接运动命令不依赖按键授权。
