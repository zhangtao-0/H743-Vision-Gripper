# 物理按键、上位机模拟与调参映射

当前版本20261023-motor-vofa-v1。代码已接入H743，软件测试/构建与实物验证分别记录；没有改动轮腿车或ESP8266工程，本修订版已烧录，详情见当前实物验收。

KEY1～4改为屏幕上下确认取消；新增KEY5/6接替舵机，EC11按压改为KEY7。模拟按下进入相同的去抖/手势，屏幕和上位机调参调用相同参数接口。以后只用实体键时切到physical或不发送模拟命令；当前散装按键不方便时可用remote模式。
