# 参数、屏幕与输入映射扩展教程

依据2026-10-22的input-map-v1源码编写。这是一套开发教学文档；本轮没有更改固件、烧录或增加实际参数。当前仍为25个参数（ID0–24）、20个执行动作、9类帮助。

建议按下表学习。先追踪现成参数，再设计新参数，最后补齐界面、保存和表格。不要把教学案例中的未来ID直接当成现有命令发送。
