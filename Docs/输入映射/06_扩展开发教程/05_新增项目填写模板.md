# 新增参数、动作与映射的填写模板

复制本表到新的任务文档，先填写再动代码。此表不是当前固件参数表，空白项不能拿来发送。

## 参数设计卡

| 项目 | 填写内容 |
|---|---|
| 设备/业务目的 | 例如控制目标变化速度；说明谁会实际使用这个值 |
| 稳定UI/文本ID及名字 | 当前占用0–24，未来追加先核对源码；不覆盖原ID |
| 类型、单位、缩放与舍入 | int32传输，实际单位与公式 |
| 最小、最大、工厂值、屏幕步长 | 说明0的含义及边界理由 |
| 读写权限 | 只读/停机写/运行可写，离线和维护期间行为 |
| 后台真实字段与setter/getter | 路径、函数、锁与ISR访问方式 |
| 旧F2/F3 ID | 无则明确“无”，禁止想当然共用UI编号 |
| 文本get/set及安全示例 | 标记当前已实现或未来提案 |
| 屏幕位置与显示长度 | 参数页/设备分类/只读状态 |
| 是否持久化 | 版本/标记/旧记录默认/保存采集/加载应用/恢复工厂 |
| 帮助分类与快捷表 | 类别、ASCII或HEX、字节、是否自动执行 |
| 验证与未完成项 | 软件测试、构建、烧录、实物逐项分开 |
