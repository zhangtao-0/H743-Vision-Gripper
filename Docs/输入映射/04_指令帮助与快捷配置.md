# 指令帮助打印与VOFA快捷配置

帮助现在提供可复制发送的集合，不要求背命令。发送`@help`后上位机依次收到9条分类请求：

```text
@help system
@help claw
@help motor
@help camera
@help pwm
@help storage
@help binary
@help keys
@help params
```

选择一条再次发送；数字`@help 0`到`@help 8`仍可用。屏幕“指令帮助”也有相同9个选项。分类中每个说明独占`#`行，命令独占下一行，例如：

```text
# Target RPM: 0..400 in current configuration.
@motor rpm 100
```

`100`可在范围内修改。`@param list`则按当前固件实时查询范围，逐项给出可写的`@param set ID 当前数字`，只读/离线项给出`@param get ID`。不是让你把整份输出一口气全部发回；只选一项执行。

文本命令使用ASCII并补CRLF（HEX为0D 0A），`FF FF...`示例需切HEX发送真实字节，不补文本换行。发送打印出来的十六进制文字不会自动执行二进制协议。

## 表格与维护

[指令帮助目录JSON](指令帮助目录.json)是固件帮助内容的编辑入口；`Tools/generate_console_help.py`生成console_help.h，检查模式使用`--check`。示例使用完整数字，不把on/off、N、CH等缩写当成可执行行。说明写明动作/范围，打印本身不产生动作。

[VOFA快捷指令CSV](VOFA快捷指令.csv)和[JSON](VOFA快捷指令.json)含分类、名称、发送方式、命令与完整bytes_hex，适合手动配置VOFA按钮/文本发送。它们是配置依据，尚不是已导入并测试过的特定VOFA项目文件。

常用按钮建议：下一项/上一项/确认/返回/快捷观测、夹取/松开/停止、电机停止、速度加减。实体键和这些按钮可同时使用；启用physical模式后按钮模拟会拒绝，但直接业务指令与调参仍保留。

帮助和参数列表限速每25ms最多一行，避免默认静默时的大列表堵塞串口；上一批未结束返回BUSY。`@quiet`取消尚未发送的列表/帮助和周期流，已经进入发送队列的少量字节仍可能随后到达。HOST和USB均会收到主动打印，蓝牙不广播这些文字。
