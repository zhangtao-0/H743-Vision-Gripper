# 实现依据、兼容与验收

轮腿车参考为本地固定提交0cf70fb0120a53d5c7caf75cd276cb3a366e8522（codex/test-6101c97）。阅读了vofa_protocol.c的参数来源标注/AA C2注册映射、param_registry.def与screen_display.c的物理UI键逻辑。该快照未找到通用远程UI键注入API，本次自行补齐，没有声称原样移植不存在的接口。servo参考当前feetech_sts_command.c的A0/B0虚拟电平、KeyGesture与F5协议。

代码入口：bsp/input_control.h定义逻辑ID/模式/API，bsp_key.c实现物理/文本合并；motor_service.c复用PC13手势和EC11目标更新；feetech_sts_command.c保留F5格式并增加模式门控/5秒保持限制。integration_console.c解析严格文本，ui_port.c向屏幕/文本提供相同参数检查和带来源的动作入口。没有新增业务裸UART句柄。

## 测试层次

- 实际BSP与UiInput主机联合测试：短按/长按/组合、物理OR虚拟、UART/USB隔离、模式、超时释放、tick回绕、临界区恢复。
- 实际电机服务测试：模拟PC13经原去抖产生换向；旋钮步进共用限幅，physical模式拒绝，不改霍尔计数；已有PID/故障/无驱动门控回归。
- 实际控制台测试：文本格式、错误ID/范围、整数溢出、多余token、来源释放、共享参数只读/范围、可执行帮助索引与参数列表；执行器/Flash为模拟接口，不连接实物。
- 帮助目录核验：生成头一致、每条文本示例被实际解析器识别，HEX长度/校验和、快捷表CRLF和参数/按键表对应。
- IAR三配置与四种H桥profile编译；指令手册/函数位置/源码基线仅刷新触及范围。

当前新增能力尚未烧录。实物待验：VOFA按钮实际发送字节/换行、混合实体+上位机操作、菜单快捷、夹爪不同模式下手势、F5持续按下续期/超时、PC13启停及模拟旋钮、真实电机驱动与PID。输入松开不是硬件急停，H桥profile0继续禁止动力输出。
