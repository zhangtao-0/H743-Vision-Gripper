# 参数、屏幕、VOFA与保存的映射

[参数CSV](参数映射.csv)列出25个当前UI/文本参数，名称从ui_port.c取得；可发送`@param list`取得实际运行值、min/max/step/state及可复制的set/get行。表中VALUE是文档模板，固件实际打印的命令会替换成当前数字。

| 接口 | 覆盖 | 行为 |
|---|---|---|
| 屏幕参数页 | ID0..24 | 编辑草稿、确认比较原值后提交 |
| `@param get 21` | ID0..24 | 查询名字/当前值/范围/步长/状态 |
| `@param set 21 100` | 可写ID | 与屏幕共用ParamRead/ParamWrite；不自动使能 |
| 原F2/F3 | 原STS ID0..20 | 沿用旧二进制定义和裁剪规则，不新增电机ID |
| 轮腿车AA C2 | 不导入本项目 | 原项目1起始的ID和IPC行为不可照搬 |

UI/文本ID0/1为机械端点只读；ID2..20为STS参数，需要在线且停止相关运动；ID21为电机目标RPM，ID22/23/24为Kp/Ki/Kd千分之一，增益需电机停机。`@param set 22 1800`即Kp=1.8。原F2接口有其既有机械标定/参数权限，不能因为编号相同就推断写权限相同。

严格文本入口拒绝越界、非整数、溢出及多余参数；状态0=受理，1=离线，2=忙，3=禁止，4=原值变化，5=失败。运行目标RPM允许调整，但程序不会因此自动使能。档位变更可能联动其它STS配置，写后用get/list复核。

## 自定义开机配置

`@profile save`、`@profile load`、`@profile clear`分别复用屏幕SAVE/LOAD/CLEAR同一服务。保存要求停止STS/电机并进入维护门控；仍不保存机械端点、不自动使能、不恢复打印开启状态。CLEAR只删除开机配置记录，不立即恢复所有RAM值或擦机械限位。

输入模式、模拟按键保持和待打印帮助不写Flash，重启清空。`@knob`是相对调速；`@param set 21`是绝对目标，二者汇入同一电机目标状态。实际霍尔计数、转速、故障不可用调参写成假反馈。
