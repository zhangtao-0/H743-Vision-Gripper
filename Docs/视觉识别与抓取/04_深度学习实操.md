# 你需要做的深度学习工作：采集到自定义分割模型

## 先建立可复现的小数据集

当前未提供快递训练数据或自定义权重，因此本版没有宣称“已训练好”。电脑端拒绝加载不含carton和black_parcel两类的模型。通用COCO预训练权重用于迁移学习起点，不等于能可靠识别你的快递。

类别约定：0 carton=矩形快递箱体；1 black_parcel=黑色塑料包裹。黑色纸箱仍标carton；外部是黑色软包装则标black_parcel，避免两种定义交叉。箱体的侧面和顶面属于同一个可见实例；多件物体分别画多边形，不把整堆快递标为一件。

建议首轮每类先准备200–400张有差异的图像，加空桌面/黑衣服/鼠标等易误检负样本；这是起步规模，不是成功保证。至少5个独立采集场次，每场都含两类，跨不同箱子和黑袋、灯光、桌面、距离、视角；最终测试要有训练未见过的包裹和拍摄条件。不要连续按S保存几百张几乎一样的画面充数。

摄像头随手运动，所以需要倾斜、旋转、靠近、拉远、轻度模糊、手部遮挡样本；也保留清晰停稳画面。240×240分辨率下，过小物体轮廓信息有限，先使目标占据明显区域并保持完整可见。记录失败场景，别只采集最好看的图。

## 标注工具

在H743目录：

```powershell
& .\Host\vision_gripper\.venv\Scripts\python.exe .\Host\vision_gripper\annotate.py
```

下拉框选类别，沿可见外轮廓依次左键点击，Backspace撤销点，“Finish object”结束一件，再标下一件；“Save & next”保存。确实没有目标时用“Negative & next”，产生空txt；有目标却没标注会教模型把它当背景。使用“Clear”后重画；输出到data/labels下同一场次目录，重访原图会读取原标注。

每行是`class x1 y1 x2 y2 ...`的归一化多边形，至少3个点，不是检测框的中心和宽高。细节依据[官方分割数据格式](https://docs.ultralytics.com/datasets/segment/)。不要画一个大矩形代替黑袋真实轮廓，不标不存在的背面，不把自己的手合并进包裹。

```powershell
& .\Host\vision_gripper\.venv\Scripts\python.exe .\Host\vision_gripper\prepare_dataset.py
```

准备器检查全部PNG都有标签、尺寸、类别、多边形合法性，按session大约60/20/20划分train/val/test，并拒绝跨集合完全相同图像和覆盖既有输出。默认写data/parcel_v1/dataset.yaml与manifest.json。少于5场次或任一集合缺类别会报错；按场次划分不能自动排除“同一纸箱换个角度”引起的物体身份泄漏，最终测试仍需你保留新实物。

## 训练环境

当前预览环境使用Python3.12，训练依赖尚未安装、CUDA尚未在PyTorch验证。建议继续在该.venv安装，避免系统Python3.14的轮子兼容问题。按核对时的[PyTorch官方安装页](https://pytorch.org/get-started/locally/)，支持的CUDA轮子示例为cu126；未来安装选项变化时以该页的Windows/Pip/Python/CUDA选择结果为准。

```powershell
$vp = '.\Host\vision_gripper\.venv\Scripts\python.exe'
& $vp -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
& $vp -m pip install -r .\Host\vision_gripper\requirements-train.txt
& $vp -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
& $vp -m pip freeze > .\Host\vision_gripper\训练环境锁定.txt
```

预训练模型和训练依赖首次可能下载较多文件；本轮没有代你下载权重或开始耗时训练。CUDA检查必须True才能使用device=0；若False先诊断轮子与驱动，不要把CPU运行误认为GPU已启用。也可明确用--device cpu做小样本流程检查。

## 训练、验证与启动识别

```powershell
& $vp .\Host\vision_gripper\train.py --data .\Host\vision_gripper\data\parcel_v1\dataset.yaml --device 0 --epochs 100 --batch 8 --imgsz 320
# 训练产生best.pt后，用保留的test场次测试；不要用test反复选模型
& $vp .\Host\vision_gripper\train.py --data .\Host\vision_gripper\data\parcel_v1\dataset.yaml --device 0 --validate .\Host\vision_gripper\runs\parcel_seg_v1\weights\best.pt
.\Host\vision_gripper\启动预览.ps1 -Port COM12 -Weights .\Host\vision_gripper\runs\parcel_seg_v1\weights\best.pt -Device 0 -Advice
```

脚本采用官方支持的YOLO11n-seg迁移学习起点，可用--model替换合适的官方/本地分割模型；模型训练接口按[官方实例分割手册](https://docs.ultralytics.com/tasks/segment/)组织。RTX4060约8GB先从imgsz320、batch8、workers0开始，显存不足降batch4/2；调大输入尺寸不会恢复原图缺失的细节。

记录训练版本、环境锁定、manifest、曲线、混淆矩阵和分割指标。识别精度与抓取建议合理率是两项指标，不能用mAP代替夹持成功。训练后将你观察到的误检、漏检、差轮廓和失败建议带回新数据版本，不修改原测试集来制造进步。
