# 新接口、屏幕与后续扩展映射

| 接口 | 当前能力 | 保留边界 |
|---|---|---|
| @video on/off | 开关USB图像发送，关闭清空建议 | 不改变电机/舵机使能；on不自动解冻摄像头 |
| @video fps N | 设置1–5的上限，默认2 | 仅RAM；实际周期还包括传输耗时，不是保证帧率 |
| @video status | 发送计数、终止计数、阶段、USB及建议 | 不主动开启周期文字 |
| @vision status/clear | 查看或清空建议 | 不把clear当机械急停 |
| @vision target SEQ U V ANGLE10 WIDTH SCORE | 接收原图像素建议，需序号与时效通过 | 通常由viewer生成，不建议手工背诵或发送固定旧序号 |
| 屏幕观测 CAMERA | 显示PC建议有效性、中心、分数与方向宽度 | 没有新增自动执行入口 |
| @help camera | 分类打印video和vision查询/开关指令 | 打印不执行，VOFA快捷表已同步 |
| 原F5/STS帧 | USART1旧入口保留 | USB CDC不因此新增旧二进制执行 |

[CSV指令映射](指令映射.csv)列出端口、参数和运行副作用；[现有参数表](../输入映射/参数映射.csv)仍为25项，没有把模型反馈塞成可写调参项。video fps未加入开机配置，模型路径和识别配置属于电脑程序；不要误认为profile save会保存它们。

当前VisionAdvice结构见[vision_link.h](../../project/App/platform/vision_link.h)。模型label在电脑显示与原图JSON中保存，首版回传几何建议不含类别编号。后续需要H743按类别分拣时，应先设计稳定的类别/目标ID协议、拒绝未知类别和任务授权，不依赖电脑模型内部临时class顺序。

要增加模型阈值或最大可用开口等参数，沿[上位机参数扩展教程](../输入映射/06_扩展开发教程/README.md)定义单位、权限、业务setter和保存策略，再扩展映射。毫米开口限制需要实际相机/夹爪标定，不能对像素width直接套毫米阈值。

将来相机有深度、机械机构定型后，再建立CameraObservation→GraspCandidate→TaskPlan→ActuatorCommand的明确接口，H743负责动作仲裁。现阶段这些后续三维任务规划未实现，也没有将GPIO、UART句柄散入电脑或UI逻辑。
