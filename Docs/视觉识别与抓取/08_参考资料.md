# 官方资料与项目证据保存方式

| 资料 | 用途 | 本版采用位置 |
|---|---|---|
| [Ultralytics实例分割](https://docs.ultralytics.com/tasks/segment/) | 迁移学习、predict/val与mask接口 | train.py、grasp.py |
| [分割数据格式](https://docs.ultralytics.com/datasets/segment/) | 类别加归一化多边形，不等同检测框 | annotate.py、prepare_dataset.py |
| [PyTorch本地安装](https://pytorch.org/get-started/locally/) | Windows/Pip/CUDA组合及验证 | 训练环境指导 |
| [Ultralytics YOLO11](https://docs.ultralytics.com/models/yolo11/) | 首版可配置的轻量分割起点 | 默认yolo11n-seg.pt |
| [Ultralytics许可说明](https://www.ultralytics.com/license) | 外部框架许可入口 | 使用或分发前按实际用途核对 |

前三项已在2026-10-23通过Firecrawl获取官方文本核对，搜索/抓取缓存位于工作区.firecrawl/h743-*；不把搜索结果混为本项目源码或硬件验证。没有下载训练图像、预训练权重或搬运整套厂商库。

项目原始图像、标签、训练产物分别保留在Host/vision_gripper/data/raw、data/labels、runs，互不覆盖；原始图像带场次/帧序号/显示标志元数据。数据清单含划分和SHA256，环境用pip freeze锁定。图像/权重默认不进入Git，重要数据需另行备份，不能依赖.venv或缓存目录保存研究成果。

本项目教学手册登记本目录，构建与主机测试输出位于20261023_电脑视觉首版。新一轮采集/训练采用新数据版本与run名称，保留失败和旧指标，避免只保留最佳结果造成误解。
