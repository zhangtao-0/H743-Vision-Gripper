# 软件验证、实物验收与修订记录

本版20261023-pc-vision-v1修改H743固件及IAR工程，新增电脑预览、标注、数据准备、训练与二维评估脚本。完整来源变更、构建与测试见[本版证据目录](20261023_电脑视觉首版/)。

## 已完成的软件工作

- 摄像头完整帧租用、分段CRC、USB独立图像发送、4秒超时释放。
- 带序号/采集时间/范围的建议接收及屏幕状态；不调用执行器。
- 电脑非阻塞串口、单帧队列、预览、原图采集；可加载自定义分割模型，生成二维候选并可选回传。
- 本地多边形标注、按采集场次划分数据、训练/测试入口和人工二维评估。
- 分类帮助、VOFA快捷表、指令手册及本学习目录同步。

主机测试覆盖真实C模块的端点缓冲所有权、文本与像素分隔、帧租用、坏CRC、旧会话/过期/越界建议及断连/发送停滞恢复；C输出由Python实际解码比对。电脑测试覆盖原色、拆包恢复、几何筛选、稳定窗口及数据泄漏检查。隐藏Tk窗口用假串口验证实际预览和关闭路径，没有访问真实COM。

## 当前仍未完成的真实工作

未烧录本版，未测USB实际帧率/延迟、VOFA并行命令响应和物理显示；未提供快递训练集，未训练自定义权重，也未验证真实模型在快递上的精度。模型推理代码接口已经编写，但不能把模拟掩码几何测试叫做真实深度模型推理验证。训练依赖/CUDA仍需用户按手册安装检查。

没有机械夹爪、深度/外参/开口标定，因此没有三维轨迹或自动抓取闭环。MG310仍保持驱动profile0，原有舵机限位/控制门控保留。

## 实物验收顺序

1. 烧录对应FD5640配置，确认原有摄像头与屏幕功能无回归。
2. USB预览稳定一分钟：记录帧数、CRC错误、终止次数、实际帧率。
3. VOFA独占USART1，同时查询状态/执行原有安全指令，记录响应及串口是否收到意外周期图像/建议文字。
4. 停止读取、拔线、相机关闭/重试，确认采集恢复、旧建议失效。
5. 完成至少5场真实采集、标注、训练和独立test；按手持验证手册记录二维失败与通过。

## 过程修正记录

首次目标构建出现USB StreamStart中同一表达式读取多个volatile变量的Pa082警告，已改为先取局部快照；本节保留初次诊断摘要，最终干净构建另列日志。测试辅助CRC头改为static inline以适配严格主机编译。回传拒绝消息改为USB专用回复，避免高频失败打印占用USART1。模拟输入/原F5协议没有重新定义。

修改前备份在Backups/pre_pc_vision_20261023.zip；旧生产基线与本版变更清单分开保存。新的资料基线仅在审阅本版差异后登记，历史失败与未验证状态保留。

## 最终核验与固件

三配置最终构建均为0错误0警告；11项电脑逻辑测试、假串口隐藏GUI、真实C传输模型及既有摄像头/控制台/屏幕设置回归通过。见[本版核验JSON](20261023_电脑视觉首版/本版核验结果.json)。当前FD5640使用[已固定保存的FD5640固件](20261023_电脑视觉首版/固件/H743_FD5640.hex)；另有OV2640/NoCamera产物。固定副本与SHA避免以后构建覆盖本版交付。软件通过不改变上文未烧录、未训练、未实物验证状态。
