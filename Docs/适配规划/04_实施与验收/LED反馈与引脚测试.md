# LED 反馈与引脚测试

状态：测试方案，**尚未在板上执行**。适用于第一版 H743 硬件：板载蓝灯 PG7、外接状态灯 PG0、外接故障灯 PG1。执行前先完成 [按设备的引脚配置](../03_硬件规划/按设备的引脚配置.md) 的接线核对。

## 当前 P2 行为

代码已实现 PG7 启动三闪/心跳、PG0 资源正常常亮及按键按住时 5 Hz 闪烁、PG1 诊断错误时 2 Hz 闪烁。下面“舵机在线/运动/掉线”属于后续 P3 业务接线，尚未启用；所有板上测试仍为未执行。实际 API 与代码位置见 [P2记录](P2复核与修改记录.md)。

## 1. 目的

1. 证明三路 LED 的 GPIO、极性、限流和时序都正确。
2. 用 LED 作为最小可视反馈，在没有屏幕/摄像头时也能判断系统状态。
3. 验证 LED 节拍不会阻塞串口、舵机和按键任务。
4. 为后续故障注入（舵机掉线、通信超时、限位异常）建立可观察信号。

## 2. 硬件接线

| LED | MCU 引脚 | 接法 | 极性 | 备注 |
|---|---|---|---|---|
| LED1（板载蓝） | PG7 | 板上 3.3V → R4 1 kΩ → LED → PG7 | 低电平点亮 | 不要外加电压 |
| LED_STATUS（外接） | PG0 | PG0 → 1 kΩ → LED 阳极 → GND | 高电平点亮 | 建议 470 Ω–1 kΩ |
| LED_FAULT（外接） | PG1 | PG1 → 1 kΩ → LED 阳极 → GND | 高电平点亮 | 红色/橙色 |

```text
3.3V ──[板载 R4 1k]──▶|── PG7（低亮）
PG0  ──[1k]──▶|── GND      （高亮）
PG1  ──[1k]──▶|── GND      （高亮）
```

注意：

- **H1-4 是 +5V，不是 GND**；外接灯的 GND 用 H1-3 或 U9-13/14。
- 先串 1 kΩ 再上电，确认亮度和电流后再考虑减小阻值；不要直接把 LED 接到 3.3V/5V。
- 用万用表二极管档确认 LED 阳极/阴极方向，避免装反。

## 3. 状态编码（第一版，尽量少）

| 状态 | PG7 板载蓝灯 | PG0 状态灯 | PG1 故障灯 |
|---|---|---|---|
| 上电/复位 | 灭 200 ms，随后 3 次 100 ms 短闪 | 灭 | 灭 |
| 自检通过、待机 | 1 Hz 心跳（亮 100 ms / 灭 900 ms） | 常亮 | 灭 |
| 舵机在线、运动中 | 1 Hz 心跳 | 5 Hz 闪烁 | 灭 |
| 舵机离线/超时 | 1 Hz 心跳 | 灭 | 2 Hz 闪烁 |
| 通信/控制异常（可恢复） | 1 Hz 心跳 | 灭 | 2 Hz 闪烁 |
| 致命错误（初始化失败） | 5 Hz 快闪 | 灭 | 常亮 |

规则：

- 心跳与故障是“系统级”；状态灯表达“业务级”。不要把三者做成互相依赖的复杂状态机。
- 所有闪烁由统一 1 ms 节拍（`HAL_GetTick` 或 `Board_Time_NowMs`）计算，不在主循环里 `HAL_Delay`。
- 上电默认先关闭外接灯，再按自检结果点亮，避免“上电即故障”的误判。
- 如果后续增加 WS2812/多色灯，不改业务层，只替换 LED 服务后端。

## 4. 软件结构（原设计草案，P2 已按角色化方式实现）

建议新增 `App/platform/board_led.c/.h`，只暴露业务语义：

```c
typedef enum {
    BOARD_LED_HEARTBEAT = 0,
    BOARD_LED_STATUS,
    BOARD_LED_FAULT
} BoardLedId;

typedef enum {
    BOARD_LED_OFF = 0,
    BOARD_LED_ON,
    BOARD_LED_BLINK_SLOW,   /* 1 Hz */
    BOARD_LED_BLINK_FAST    /* 2 Hz / 5 Hz 由配置决定 */
} BoardLedPattern;

void BoardLed_Init(void);
void BoardLed_Set(BoardLedId id, BoardLedPattern pattern);
void BoardLed_Task(uint32_t now_ms);
```

- `board_led.c` 内部保存每个灯的引脚、有效电平、相位计数；`BoardLed_Set` 只改模式，`BoardLed_Task` 非阻塞刷新。
- 业务层只调用 `AppFeedback_ReportServoOnline()` / `AppFeedback_ReportFault()` 之类的语义接口，不直接写 GPIO。
- 引脚和极性放 `board_config.h`，换板只改配置。

## 7. 安全与常见错误

1. **把 H1-4 当 GND**：会短路 +5V，必须避免。
2. LED 不串限流电阻：可能烧 GPIO 或 LED。
3. 用 5V 直接驱动 LED 再灌入 GPIO：反向电压/电流可能损坏引脚。
4. 在中断里做 LED 长延时：会丢串口字节、错过舵机应答。
5. 上电默认点亮故障灯：会掩盖真正的启动失败；默认先灭。
6. 外接灯与屏幕背光共用引脚：PG12 已被 LCD 背光占用，不能再用。
