## 4. 当前行为（预期，未上板）

1. 上电 LED 先灭 200 ms，再三次短闪，PG7 进入 1 Hz 心跳。
2. HOST（USART1，115200）输出启动标识。
3. 只读探测：`PING → ID → MODEL → BAUD → LIMITS → 15B 反馈`；每 500 ms 一行：
   ```text
   P3 st=ONLINE online=1 id=0 model=0x.... baud=... rate=... bstep=... pos=... ang10=... mV=... T=... ...
   ```
4. 探测到 ONLINE 后自动切到 command/control：
   - `FeetechStsBus_Init()` 重新初始化总线（保留已探测的波特率）；
   - `FeetechStsControl_Init()` 上电状态 `local_write_enable=0`，**不下发目标**；
   - `FeetechStsCommand_Init()` 只打印提示文本；
   - 之后 `FeetechStsCommand_Task()` 处理按键 A0/B0 与 VOFA 帧命令。
5. 在 ONLINE 之前，KEY1 单击重新探测；ONLINE 之后，按键交给原夹爪状态机。
6. 若从未探测到 ONLINE，固件停留在只读/重试，不会动作。

## 5. 安全边界

- P3a 探测阶段只发 `PING(0x01)`/`READ(0x02)`，主机测试逐帧验证无 WRITE。
- P3b 接入后，只有以下入口会触发运动：
  - 实体键 A0/B0（原 F103 逻辑）；
  - VOFA 收到的飞特官方帧 / 主机命令。
- `FeetechStsControl_ConfigureServo()` 不会在上电自动调用；扭矩/模式/目标只在首次动作逻辑中写。
- 首次上板建议拆下夹爪负载、限流供电，先只读，再按一次 A0 观察小幅动作；随时可断电。

## 6. 已知限制

- P3b 只完成**编译/链接接入**，没有动过真实机械；动作方向、开合端点、限位保护都需要上板确认。
- P3a 主机测试不能证明真实电平、1 Mbps/9600 时序、转接板回显和舵机实际应答。
- VOFA 当前是文本行遥测，不是 JustFloat/FireWater；正式帧协议待 P4/P5 前定。
- 屏幕/摄像头/PWM/Flash 持久化仍未接入；PWM 代码参与编译但不初始化。
- `.ioc` 未用 CubeMX GUI 重新打开校验。
