## 5. 当前可观察行为

上电后（**尚未在板上验证**）：

1. `MX_GPIO_Init` 先把 PG7 置高（灯灭）。
2. USART1/2/3 分别以 115200 / 1 Mbps / 115200 初始化，NVIC 使能。
3. `App_Init` 通过 USART1 发送 `\r\n[H743] P1 minimal system\r\n`。
4. `App_Task` 每 500 ms 翻转 PG7，形成 1 Hz 心跳。
5. 不初始化舵机总线任务、按键、蓝牙、VOFA、PWM、屏幕、摄像头、Flash 持久化。
