# P3 上电只读验证步骤（动作前）

状态：待执行。当前 P3 HEX 上电先只读探测（HOST=VOFA、SERVO=1 Mbps/自动回退、只发 PING/READ/READ_FEEDBACK），**ONLINE 后会自动接入 command/control**。只读阶段不会动；接入后按 A0/B0 或发 VOFA 帧才会动。**只读检查期间不要按键、不要发帧。**

## 1. 接线

| 连接 | 说明 |
|---|---|
| USB-TTL → H1 | H1-3=GND、H1-5=RX、H1-6=TX；**不要接 H1-4（+5V）** |
| TTL 转接板 → U9 | 转接板 TX → PA3(U9-20)，转接板 RX → PA2(U9-11)，GND → U9-13/14 |
| 舵机电源 | 按铭牌独立供电；转接板与 MCU 共地 |
| 舵机 | 先空载/脱离机械夹爪，确认转向和限位前不要装负载 |

上电顺序：先接好地线和信号，再给舵机上电，最后复位 MCU。第一次测试建议限流电源或串保险。

## 2. 串口设置

- 端口：USB-TTL 对应 COM。
- 115200、8N1、无流控。
- 打开串口后复位板子，应看到：
  ```text
  [H743] P3 STS probe -> command/control; HOST=115200 (ID=0, 270deg)
  P3 st=PING online=0 id=0 rate=1000000 bstep=0 ...
  P3 st=READ_ID ...
  P3 st=READ_MODEL ...
  P3 st=READ_BAUD ...
  P3 st=READ_LIMITS ...
  P3 st=ONLINE online=1 id=0 model=0x.... baud=... rate=... bstep=... pos=... ang10=... mV=... T=... ...
  ```

ONLINE 后固件会自动执行 `FeetechStsBus_Init + Control_Init + Command_Init`，串口会再出现 command 层的复位/标定/范围提示，P3 文本遥测停止。**此时不要按键、不要发帧**，先把只读数据记录完；断电再进入动作测试。

## 3. 判读

| 现象 | 含义/处理 |
|---|---|
| 一直 `st=PING online=0`，`to` 增加且 `bstep` 到 9 | 所有候选波特率都没回：查 ID=0、TX/RX 是否交叉、转接板是否供电、共地 |
| `st=READ_ID` 后卡住 | PING 回了但 READ 没回：查转接板回显/方向、协议帧是否被裁剪 |
| `model=0x0000` | 型号读回失败或地址不匹配；记录原始行，先不要动作 |
| `baud` 与 0 不同，或 `rate` 不是 1000000 | 说明实际波特率与源码默认不同；记录 `rate/bstep`，不要改 EEPROM |
| `pos` 不变、`mV/T` 合理 | 正常只读；舵机可能已卸力/未上力 |
| `online` 变 0 后自动 `RETRY` | 掉线重试生效；查线/电源 |
| PG0 常亮 | 探测到有效应答 |
| PG1 2 Hz | 通信/错误；看 `err/to/pe/te` |

`ang10` 是角度×10；`mV` 是电压毫伏；`T` 是摄氏度；`cur` 是 mA；`load` 是原始负载；`err` 是舵机 ERROR 字段。

## 5. 通过标准

1. 连续 10 min 遥测，`online=1` 稳定，无持续 `to/pe/te` 增长。
2. 读回的 ID、型号、波特率索引与实物/上游配置可解释。
3. 拔掉舵机信号后 1 s 内进入 RETRY，插回后自动恢复 ONLINE。
4. 示波器/逻辑分析仪确认 PA2 发送、PA3 接收，1 Mbps 波形无明显过冲/振铃。
5. 测试期间舵机不动作、不上力、不发烫。

## 6. 下一步

只读数据通过后，P3b 已自动接入（`APP_P3_MOTION_ENABLE=1`）：保持夹爪空载，按一次 A0 观察是否按原逻辑小幅夹取；异常立即断电。不要在上电流程直接调用 `FeetechStsControl_ConfigureServo` 或 `EnableTorque`。动作方向/端点/限位确认后再接机械负载和 VOFA 帧命令。
