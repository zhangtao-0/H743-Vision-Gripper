# About [](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c3/about.html\#about "Permalink to this heading")

[\[中文\]](https://docs.espressif.com/projects/esp-idf/zh_CN/v6.1/esp32c3/about.html)

This is documentation of [ESP-IDF](https://github.com/espressif/esp-idf), the framework to develop applications for ESP32-C3.

The ESP32-C3 is a 2.4 GHz Wi-Fi Bluetooth Low Energy combo SoC, which integrates a 32-bit RISC-V RV32IMC single-core processor.

![Espressif IoT Integrated Development Framework](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c3/_images/about-doc.png)

Espressif IoT Integrated Development Framework [](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c3/about.html#id1 "Permalink to this image")

The ESP-IDF, Espressif IoT Development Framework, provides toolchain, API, components and workflows to develop applications for ESP32-C3 using Windows, Linux and macOS operating systems.
