# 实验记录模板

每次复制一份并填写，失败结果也保留。文件名建议：日期_设备_实验目的.md。

| 项目 | 本次填写 |
|---|---|
| 日期、操作者 | |
| 实验问题与假设 | |
| 板卡、设备型号、接线图 | |
| 供电、电平、外部驱动 | |
| 源码/构建目标/固件哈希 | |
| 是否已下载、下载时间 | |
| 参数、输入、采样周期 | |
| 预期现象与通过条件 | |
| 逐步操作 | |
| 实际观察、原始日志、截图位置 | |
| 结论及其适用范围 | |
| 下一项排查或复验 | |

一个有效结论例子：“在这份固件、此接线和此供电下，串口环回连续收到 1000 字节且计数一致。”不要据此写“所有通信功能通过”。编译通过只能证明编译范围内的语法、类型和链接关系；电机动作、调速稳定性和图像质量必须另有实物证据。
