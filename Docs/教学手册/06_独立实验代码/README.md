# GPIO / UART 独立实验片段

本目录的两个 `.c` **不在生产IAR工程注册**。本轮只用当前IAR/目标HAL做编译检查，没有链接/烧录为一个完整实验固件，也没有新波形测试。编译结果见教学资料核验报告。

- `lesson_gpio.c`：PG7低有效LED初始化与非阻塞500ms翻转；不要与BoardLed同时拥有PG7。
- `lesson_uart2.c`：PA2/PA3、AF7、115200，完整RCC/GPIO/UART/NVIC/IRQ/回调/小接收环；它使用的IRQ/回调在生产工程已存在，不能重复加入同一目标。

## 怎样做成独立实验

在一个单独IAR目标中保留匹配H743的CMSIS/HAL、HAL模块开关、启动文件、SystemInit、链接文件和系统时钟；不加入本项目App和重复的IRQ/回调。启动后依次 `HAL_Init`、正确的系统时钟配置、Lesson初始化，主循环运行相应Task/Pop。

UART实验先断开STS适配器，选用PA2/PA3回环或外部UART工具二选一。回环时可发送一份固定字节序列，用Pop比较返回数据；不要写成自动把收到的每个字节再次回发，否则本机回环会形成循环数据。外部UART工具使用115200/8N1和正确电平/共地。

本例UART参数与生产STS的1Mbps不同，目的是隔离学习运输链路。生产工程仍使用board_uart和uart_router，不应为实验覆盖它们。
