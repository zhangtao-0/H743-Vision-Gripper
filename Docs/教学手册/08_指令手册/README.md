# 操作与指令入口

[统一指令手册](../../指令手册/README.md)把原servo官方帧、F0–F4管理、F5业务输入与H743的`@`控制台放在同一查询入口，分别注明接入通道、参数单位、回复、状态前提和副作用。

先看[接口能力矩阵](../../指令手册/00_总览/01_入口与分层.md)，再查[全部文本命令](../../指令手册/01_文本控制台/01_完整AT指令表.md)或[按任务选择命令](../../指令手册/03_使用与排查/01_按任务速查与排查.md)。USART1与USB CDC能力不同；USB回显二进制不代表动作执行。

本轮仅建立文档、修订旧表入口提示与离线组帧/核验工具，没有改变固件协议、发送动作或设计屏幕菜单。返回[项目教学手册](../README.md)。
