# H743 智能可视化机械臂夹爪：项目名片

本项目库把一份真实工程作为学习案例。知识原理放在外部知识库，本目录解释这里的代码为什么这样组织、数据实际经过哪些函数，以及已有证据到哪一步。

## 对象与目标

主控为STM32H743ZIT6，开发板LXB743ZI-P1。目标设备包括STS3215-C001串口舵机、FD5640/OV5640摄像头、1.54寸SPI屏、四键/反馈灯、VOFA/HOST、USB CDC、RTC、SD、QSPI及后加MG310/EC11速度闭环。

“智能可视化机械臂夹爪”是系统方向。当前摄像头采集与屏幕预览不等于已具备目标识别、坐标变换、轨迹规划或视觉自动抓取算法。

## 截至2026-10-22文档核查的边界

| 模块 | 当前源码/证据 | 学习时应怎样表述 |
|---|---|---|
| 摄像头+屏幕 | 旧固件现场329帧、0超时，用户确认随动 | 有对应版本的板上预览证据 |
| STS舵机 | ID0/1、1Mbps只读查询rawRx=0 | 协议软件存在，硬件链路仍待复验 |
| MG310/EC11/PID | 三目标编译与主机模型通过，无H桥 | 软件接入，电机版本未烧录/未实机调参 |
| SD/FatFs | 源码路径完整，先前SD=0/FS=0 | 不能写成实卡文件读写已通过 |
| QSPI/RTC/USB等 | 有识别/状态与相应软件路径 | 分项查证，不扩大成全系统验收 |

本轮仅写教学资料，没有复测硬件，没有更改固件或重新烧录。旧现场结果的HEX和当前电机扩展HEX不同，不能把旧验收标签自动贴到新版本。
