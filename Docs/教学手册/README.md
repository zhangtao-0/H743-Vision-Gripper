## 应当建立的整体图景

`main / 时钟与底层初始化 → 板级资源与适配 → 设备驱动 → 服务与状态机 → App_Task`

接收方向通常是 `引脚 → 外设 → IRQ → HAL → 回调 → 队列/状态 → 主循环消费`；发送方向反过来。摄像头还需要 DCMI、DMA 和可访问的内存，电机还需要外部 H 桥。句柄集中映射减少业务代码改动，但更换 UART 仍须同步初始化、GPIO AF、IRQ 和时钟。

## 当前证据边界

观察时点 2026-10-22。历史摄像头版本已有预览随物体变化的用户反馈；当前含 MG310 扩展的源码通过过软件构建，不能据此认为该版本已下载运行。STS 尚无在线运动证据；MG310 尚无 H 桥、实物闭环和整定证据，`MOTOR_DRIVER_PROFILE=0` 保留禁止功率输出。

原教学阶段仅新增资料和独立示例；后续屏幕UI阶段修改了生产固件/工程配置，但未烧录设备，见本页后续版本入口。确切核验结果见[资料维护与核验](05_维护与证据/02_资料维护与核验.md)。阅读时以代码和具体日志为证据，避免把计划引脚、历史固件现象和当前源代码混在一起。
