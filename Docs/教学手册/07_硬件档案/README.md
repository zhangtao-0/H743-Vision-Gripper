# 项目硬件、供电与替换

当前项目的硬件清单、部件用途、供电与替换条件集中在[硬件档案](../../硬件档案/README.md)。它与引脚矩阵互补：引脚表回答“接哪里”，本档案回答“为什么用它、需要什么电源、换一种设备会影响什么”。

建议顺序：[清单](../../硬件档案/00_总览/01_硬件总清单.md) → [整机供电](../../硬件档案/01_供电设计/01_开发板与整机供电.md) → [JDY-31与HC-08](../../硬件档案/02_设备档案/02_蓝牙JDY与HC08.md) → [替换矩阵](../../硬件档案/03_替换与验收/01_硬件替换矩阵.md)。电机/舵机与视觉等分别有设备档案，实际值以来源与实物验收记录为准。

用户本轮确认当前蓝牙为JDY-31，底板和固件版本仍未确认。没有新增实物测试，也没有改变 `MOTOR_DRIVER_PROFILE=0`。通用方法见[供电与替换知识章节](../../../../../../20_Knowledge-研发知识库/09_系统学习手册/05_系统工程/04_供电与硬件替换的判断方法.md)。
