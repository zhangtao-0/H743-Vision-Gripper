# 每次读一个模块，留下什么结果

本章给出读代码任务，不要求第一遍读完所有库实现。每项输出一张小图或一页笔记，放在个人实验记录中。

## GPIO与按键

从board_config找极性与引脚，到BoardLed/Key_Init找时钟和模式，再到App_Task找事件消费。记录“低电平”在输入、输出和业务含义中的区别。检查PC13新按压键为何不走原四键数组。

## UART与STS

标出句柄定义、角色绑定、MSP、IRQ、回调、单字节缓存、解析器和P3取包。选一个PING应答，写出哪个函数先看到原始字节、哪个函数才认定online。

## 屏幕与相机

先找SPI_LCD_Init、LCD_SetAddress、LCD_CopyBuffer，不从字体表开始。相机先找Init、DMA启动、回调标志、完整帧条件、分条发送，再研究寄存器表中格式/尺寸/时钟项。

## 电机

先读纯C MotorControl_Step，再读MotorService_Tick1ms，最后board_motor。把单位标在变量边上：count、RPM、秒、毫秒、‰。用一条配置说明驱动profile=0为何拒绝启动。

## 存储与通信中间件

先看BoardStorage入口，然后向下读diskio或QSPI；先看UsbConsole_Task，再向下看CDC和PCD。避免把设备库每个内部函数都当作首轮学习目标。
