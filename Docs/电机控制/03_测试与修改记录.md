# 测试、限制与修改记录

## 本轮实际完成

1. 新增纯 C `motor_control`、`motor_service`、`board_motor`、集中 `motor_config`；复用当前 H743 HAL，不导入其他版本固件。
2. TIM1 PE9/PE11 读取 A/B，16位回绕差分转有符号增量；TIM12 PB14/PB15 条件输出20kHz PWM；TIM6 1ms采样、100Hz速度PID。
3. EC11 PG2/PG3，默认4边沿/格，支持2边沿型；PC13可用EC11按压开关，短按换向、长按800ms启停。原有四按键不变。
4. 新增斜坡、积分限幅/抗饱和、测量微分/滤波、换向停稳等待、无反馈/反向反馈/定时异常停机。故障锁存，清故障后不自动启动。
5. `@motor` 控制台、LCD目标/实测转速与方向/故障；PG1电机故障5Hz闪烁；维护命令在电机使能时拒绝。
6. 按用户提供参数图把最初未知CPR改为霍尔13PPR×4×20.409=1061.268；提供GMR500PPR配置。用户纠正首根线为M+，记录完整线序M+、GND、B、A、VCC、M-。
7. 用户明确无驱动板。因此保留driver=0，禁止启动，不配置功率输出。没有把微控制器GPIO当电机驱动，没有宣称物理运动已完成。
8. 更新IAR工程、设备引脚CSV/总矩阵/旧规划补记，PG4/PG5保留。源码备份 `Backups/project_pre_MG310_20261021.zip`。

## 软件验证

- `python Tools/run_motor_tests.py`：编译真实motor_control与motor_service，替换板级I/O为确定模型。覆盖正负速度闭环、负载扰动、非零Kd、反转等待/超时、反馈缺失/符号错误、PWM饱和抗积分累积、目标零停机、计数器正反回绕、EC11抖动/非法跳变/2与4边沿、缺驱动拒绝启动、控制中断间隔异常、短按与长按分离、运行中参数保护、PRIMASK恢复。
- 一阶模拟模型200RPM目标，在等效降低70RPM空载速度的负载扰动后恢复至约199.99RPM。这个值是模型结果，不能当作MG310实测误差。
- `python Tools/check_motor_profiles.py`：用实际IAR/目标HAL分别编译profile 0/1/2/3，全分支0错误、0警告；未连接对应H桥，不包含电气验证。
- P2 UART/LED/按键、P3只读舵机、摄像头状态机、原控制台/Flash/PWM回归均通过。控制台测试新增电机命令路由和使能时维护拦截。
- IAR配置 `H743_VisionGripper`、`H743_VisionGripper_OV2640`、`H743_VisionGripper_NoCamera` 均0错误、0警告，日志见本目录各配置.log。
- ST官方引脚XML核对TIM1 PE9/PE11和TIM12 PB14/PB15，结果见 `ST引脚复用核对.json`。

## 未完成的实机验收

**电机功能版本未烧录；没有真实H桥/动力输出/转速闭环测试，没有实机PID增益标定。** 板上的先前摄像头修复固件及其现场证据保留。构建汇总区分当前HEX与已验证旧HEX，不能把旧硬件验收沿用到新固件。

尚缺 H桥模块型号及其真值表、限流/散热、电源能力和实机反馈方向核对。用户参数图明确不可堵转，软件无脉冲异常检测不能替代驱动限流，也不作为机械堵转试验许可。

驱动到位后按 [操作与验收](02_软件配置与操作.md) 先手转计数、再低速空载、再变速/反转、最后轻负载扰动；记录电源、驱动、增益、CPR、实测转速和误差，才可报告实机稳速完成。

CubeMX `.ioc` 仍为已有工程生成基线，新增外设由App平台初始化。重新生成时必须保留 `App` 和IRQ USER CODE，并检查IAR新源文件注册；完整平台初始化不能仅根据ioc已有引脚判断。
