# MG310：在VOFA操作旋钮、按键并观察PID

当前方案：TB6612 A通道驱动，电机霍尔A/B测速，SM0488050V0.1调速旋钮。默认目标400RPM，上电保持关闭。正在使用的接线、烧录及测试状态见[本轮记录](20261023_VOFA调速与波形/README.md)。

## 1. 分清两个编码器

电机自带的霍尔A/B是反馈传感器，接PE9/U9-36、PE11/U9-38，用TIM1测实际轴速；旋钮模块的A/B用于改变期望速度，接PG2/U10-57、PG3/U10-58。它们不能互相替代。

SM0488050V0.1有VCC/GND/B/C/A五针，用户说明额定5V。用户已确认C为按压输出，接PC13/U10-7（KEY7），按下低有效极性待实物核对。它不是裸EC11，**不能把模块C直接当公共端接地**。

最新直接接线方案见[EC11五伏模块](20261024_EC11五伏模块接线/README.md)：PG2/PG3/PC13均已核对为FT输入，修正版禁用内部上下拉后可接当前5V模块信号。下面的电平缓冲方案仍是可选方式。可用供电3.3V、输入容许5.5V的[SN74LVC125A](https://www.ti.com/product/SN74LVC125A)做三路同相缓冲：模块A/B/C→1A/2A/3A，1Y/2Y/3Y→PG2/PG3/PC13，三路低有效OE接GND，芯片VCC=3.3V并加去耦，所有地相连。按实际封装数据表连引脚，不按芯片外形猜脚号。旧GPIO上拉版本不得直接接5V信号；本轮NOPULL修正版条件见最新接线方案。模块仍用5V供电。

旋钮默认每格4个有效边沿、每格5RPM，范围0～400。400已在上限，先反向减速才能观察变化；若一格只走半格或两格，核对每定位点2/4边沿配置，不要修改电机测速CPR来补偿旋钮。

## 2. 实体与VOFA是同一操作

| 操作 | 实体 | VOFA发送ASCII并加CRLF |
|---|---|---|
| 增速5RPM | 旋钮一格 | `@knob 1` |
| 减速5RPM | 反向一格 | `@knob -1` |
| 启停切换 | KEY7点按后释放 | `@key 7 tap` |
| 换向一次 | KEY7按住至少1秒 | `@key 7 press 1200` |
| 设400RPM | 参数页设置 | `@motor rpm 400` |
| 暂停，保留目标 | 点按停止 | `@motor disable` |
| 明确停止并清零目标 | 专用停止动作 | `@motor stop` |

长按释放后不会又执行一次启停。正常启停暂停保留目标值，便于下次继续；故障或专用stop保持清零语义。把目标设为0不等于断电。反转时控制器先取消驱动、等待低速，再切换方向并重新爬升，不直接用大占空比硬反转。

先执行`@input mode mixed`，让实体和模拟输入同时可用；仅实体用physical，纯模拟用remote。切模式时全部键释放、机构停止。physical模式拒绝模拟旋钮/按键，这是输入来源选择，直接业务命令仍存在。

如果电机M+/M−还直接接电源，上述命令无法断开外部动力，也不能实现调速；必须先按[TB6612接线教程](05_H桥原理制作与TB6612接线.md)改接。

## 3. 配置VOFA看目标和真实曲线

1. 用USART1的USB-TTL端口，115200、8数据位、无校验、1停止位。最近实物测试为COM12，实际插口变动后重新核对；原生USB COM11留给图像或文字诊断。
2. 数据协议选择**JustFloat**。它是小端float32数组，末尾`00 00 80 7F`，见[VOFA官方说明](https://www.vofa.plus/docs/learning/dataengines/justfloat/)。此处只改变“接收波形数据”的解析，发控制命令仍选ASCII并加回车换行，不能把`@knob 1`按HEX发送。
3. 发送`@quiet`，稍等，再发送`@motor plot on`。波形目标周期20ms、名义50Hz主动发送；上电默认不发送。开始时若HOST正在发送旧文字，可能拒绝开启，等旧队列发完重试。绘图状态可在USB文字口查询`@motor plot status`。
4. 将波形图绑定CH0、CH1、CH2：分别命名“用户目标”“实测RPM”“PID斜坡参考”，设为不同颜色和同一纵轴。CH0/CH1用于看期望与实际，CH2用于判断当前实际送入PID的参考，而不是把斜坡限制误判成PID慢。
5. 再加CH4看PWM，CH5看误差；CH6使能和CH7故障适合独立小图。X轴按50Hz，即20ms/点；若软件版本仅按样本序号显示，换算时间时用该名义周期；主循环忙时遥测会延迟/跳过，不把它当精确采样时钟。PID本身仍由定时器100Hz执行。
6. 新建发送按钮，按上表配置命令；“旋钮+”“旋钮−”两个按钮可模拟调速，启停按钮发送`@key 7 tap`，换向按钮发送`@key 7 press 1200`。这份[控件映射CSV](20261023_VOFA调速与波形/VOFA控件操作映射.csv)是填写依据，不是声称已在你电脑VOFA中导入的工程文件。
7. 结束后发送`@motor plot off`或`@quiet`，再切回文字查看`@help motor`。关闭波形不会停止电机，需要另外点按停机或发送停止命令。

绘图时HOST输出被JustFloat独占，防止文字或原舵机二进制应答污染曲线；HOST仍能接收上述文本命令，文字回复到USB口可见。想在VOFA接收窗口打印帮助时先关闭绘图。不要同时开启旧`@stream on`CSV或舵机周期打印来拼成电机曲线。

## 4. 八个通道怎样理解

| 通道 | 含义 | 单位 |
|---|---|---|
| CH0 | 用户目标×请求方向；停机仍保留旋钮设定 | RPM |
| CH1 | 霍尔计数换算并滤波的实际转速 | RPM |
| CH2 | 实际斜坡参考×当前方向；禁能、换向滑行时为0 | RPM |
| CH3 | 未滤波的实际测速 | RPM |
| CH4 | 当前实际输出命令，范围−950～950 | 千分比 |
| CH5 | CH2−CH1，跟踪误差 | RPM |
| CH6 | 控制器是否启用 | 0/1 |
| CH7 | 故障码 | 0正常，1无反馈，2换向超时，3反馈反向，4调度超时，5超速 |

没有霍尔脉冲时真实测速为0，不会复制400作为假反馈。直接供电导致电机在转但H743禁能时，会看到CH1非零、CH4/CH6为0；这是外部动力尚未交给H桥，并不是PID已经闭环。

## 5. 先低速核对方向，再调PID

先确认当前L298N接线、电源限流、机械可自由转动。第一轮不要从400RPM满目标开始；保持停止，发送`@motor rpm 50`，再点按启用。确认CH1符号与CH2一致；方向错应停止后检查M+/M−或霍尔A/B相序，统一修改输出/编码器方向配置，不用负Kp掩盖接反。

核对一圈计数：霍尔版输出轴约1061.268 counts/rev，来自13PPR×4×20.409；不同批次应实测校准。测速系数错误时，曲线看似吻合也不代表物理RPM正确。

当前初始增益Kp=1.8、Ki=5、Kd=0；它们是起点，不是实物调优结果。先正常停用，再逐项改：`@param set 22 1800`、`@param set 23 5000`、`@param set 24 0`。数值单位为实际增益×1000，增益运行中拒绝修改。可以先关闭积分/微分，观察P，再逐步加I减静差；D用于抑制变化，但会放大测量噪声。

用50→100→200等目标阶跃，看CH2/CH1的超调、稳定时间和误差；用CH4判断是否已饱和。当前参考斜坡1000RPM/s，0到400约0.4秒。2026-10-24实际使用L298N、用户报告VM=10.3V；原TB6612/4.5V为历史接线；若PWM长期接近950仍达不到400，先查供电、负载和驱动压降，不靠加大Ki强行弥补。

参数21的工厂值改为400，旧自定义开机配置仍优先保留。需要把400保存成自己的开机目标，停止后执行`@motor rpm 400`、`@profile save`；保存不自动启动。不要用`@profile clear`只为改电机速度，因为它还会清除其他开机配置。
