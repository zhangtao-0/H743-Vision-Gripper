# 硬件参数与按设备接线

> 当前驱动为L298N、PB14→ENA（非PE13），霍尔A=PA8、B=PE11；EC11五伏接法见[最新旋钮名单](20261024_EC11五伏模块接线/README.md)。文末TB6612电气部分属于旧驱动方案。

## 已确认参数

用户电机标识：WHEELTEC MG310P20_7.4V，F0060299。参数来自本目录保留的用户截图；厂家批次/后缀资料尚未提供。

| 项目 | 参数 |
|---|---|
| 电机类型 | 有刷直流减速电机，A/B 相编码器 |
| 标称/实际减速比 | 20:1 / 20.409:1 |
| 电机额定电压 | 7.4V；截图建议 7–13V，首次按额定 7.4V 使用 |
| 空载 / 额定转速 | 500±13% / 400±13% RPM |
| 空载 / 额定 / 堵转电流 | ≤220mA / ≤500mA / ≤2A |
| 堵转许可 | NO；软件异常停止不等于电流保护 |
| 霍尔 / GMR 编码器 | 13 PPR / 500 PPR |
| 编码器电源 | 3.3–5V，内部上拉至 VCC；当前接5V，数字输入为FT且无内部上下拉 |
| 输出轴 x4 计数 | 霍尔 1061.268 / GMR 40818 counts/rev |
| 用户确认的线序 | 从用户指定第一根起：M+、GND、B、A、VCC、M-；不推断线色、插头朝向 |

`输出轴计数 = 电机端单相 PPR × 4 × 20.409`。默认按用户所称霍尔版配置；若实物是带后盖 GMR 版，必须切换 `MOTOR_ENCODER_GMR=1`，二者不能混用测速系数。

## 设备 1：电机及反馈编码器

| 设备信号 | 接线 | MCU/板连接器 | 说明 |
|---|---|---|---|
| M+ | H 桥 OUT1 | 不接 GPIO | 动力输出，不是 VCC |
| M- | H 桥 OUT2 | 不接 GPIO | 与 M+ 形成双向动力回路 |
| 编码器 GND | 公共地 | 可用 H1-3 GND | 与驱动、MCU、动力电源地相通 |
| B | PE11 | U9-38，TIM1_CH2 AF1 | 硬件四倍频 |
| A | PA8 | U10-47，TIM1_CH1 AF1 | 硬件四倍频 |
| 编码器 VCC | 板上+5V | 不接动力电源 | PA8/PE11为FT输入，内部上下拉禁用 |

引脚复用已通过 [ST 官方 STM32H743ZITx 数据](https://github.com/STMicroelectronics/STM32_open_pin_data/blob/master/mcu/STM32H743ZITx.xml) 核对，核对结果见 `ST引脚复用核对.json`；连接器编号来自项目原理图引出表。

## 设备2：SM0488050V0.1旋钮模块

用户确认模块5V供电、C为按压。A→PG2/U10-57、B→PG3/U10-58、C→PC13/U10-7（KEY7）。三脚均为FT输入，本轮修正版内部上下拉禁用，可接当前5V模块信号，依赖外部上拉或模块驱动。C不是公共端，不接GND。完整名单和使用方法见[EC11五伏模块](20261024_EC11五伏模块接线/README.md)。

默认每格5RPM、0～400；点按启停、长按1秒换向，长按释放不额外启停。必须开启Motor keys授权；physical/mixed模式接受实体输入。每格2/4边沿、C按下低有效仍待实体测试。

## 设备4：H桥接口与历史TB6612方案

| 配置 | 控制接口 | MCU / 引出 |
|---|---|---|
| profile=0，无驱动选项 | 无驱动 | 不启用下述输出 GPIO/PWM |
| profile=1 | EN/PWM + IN1 + IN2 | PB14 U9-45 + PE10 U9-37 + PE12 U9-39 |
| profile=2，历史TB6612配置 | PWMA + AIN1 + AIN2 + STBY | 同上，另 PE13 U9-40，STBY 高有效 |
| profile=3 | 两输入 PWM，例如符合该真值表的 DRV8871 | PB14 U9-45 → IN1，PB15 U9-48 → IN2；仅一侧 PWM，另一侧低 |

这些是控制接口适配模板，不表示所有同名驱动模块接法都一样。驱动 VM 接独立 7.4V，OUT1/OUT2 接电机 M+/M-，GND 共地；驱动逻辑接口须兼容 3.3V，电流/散热和限流应覆盖电机工况。

可考虑 [TI DRV8871](https://www.ti.com/product/DRV8871) 双输入 PWM 模块：芯片工作输入 6.5–45V、3.6A 峰值，支持电流调节；峰值不是模块持续输出保证，具体板子的限流设定、散热和接线需核对。软件已预留 profile=3，未将未选定硬件假装成已安装。

## 保留资源与冲突

TIM1 专用于本电机反馈；TIM12 专用于 20kHz 电机 PWM；TIM6 专用于 1ms 调度（每 10 次 PID）。TIM4 的 PD12/PD13 50Hz 舵机 PWM 不变，不能用它同时生成电机 20kHz。TIM6_DAC 共享中断当前归本模块，后续 DAC 功能需统一分发。

PG2/PG3 从扩展预留转为 EC11；PG4/PG5 仍明确预留。调试 PA13/PA14、PB3/PB4/PA15 及摄像头 PC4/PA5 保留。PB14/PB15 的占用会限制未来 USB HS 复用，当前 PA11/PA12 USB FS 不受影响。PE10/PE12/PE13 为不同驱动接口条件预留。

TB6612当前实接以[H桥教程](05_H桥原理制作与TB6612接线.md)为准，VM可先用当前4.5V，不保证400RPM可达；逻辑VCC明确为3.3V。
