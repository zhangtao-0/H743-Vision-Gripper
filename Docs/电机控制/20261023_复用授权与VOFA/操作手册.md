# 复用按键、调试授权与VOFA自测

本页对应20261023-debug-grants-v1，取代此前“按键始终控制电机/舵机”的操作说明。本轮仅软件构建和主机模拟测试，未烧录，未连接串口/ST-Link。使用本页新增命令和页面前，需烧录本轮固件。以前实际烧录版本仍为motor-vofa-v1。

## 一、授权和页面

主页新增DEBUG / KEY GRANTS。KEY1上下中的上一项，KEY2下一项，KEY3确认，KEY4取消保持原来行为。KEY3+KEY4同时按下立即进入DEBUG，再按返回之前页面（包括参数编辑草稿）；普通KEY4返回主页。上位机同样可发送`@keys 12 100`模拟快捷键。

调试页分别提供STS keys、Motor keys、PID plot ONLY、Quiet all streams。确认前三项切换ON/OFF；Quiet关闭输出流。STS和Motor为独立权限，可以同时ON；离开页面仍有效，上电/复位均OFF，未纳入开机配置保存。开关不会主动启动或停止现有运动：要停车请显式停机。切换授权时先释放KEY5～7、远程按键和旧F5/Bluetooth按键；否则返回BUSY/accepted=0。

| 输入 | 舵机授权ON | 电机授权ON |
|---|---|---|
| KEY5/PC0 | 原A0手势（夹爪/行程选择） | 单击启停，停用保留目标转速 |
| KEY6/PC1 | 原B0扫描/停止/双击换向 | 单击减5RPM，双击加5RPM |
| KEY5+6 | 原组合标定手势 | 无专用组合动作；各自事件仍广播 |
| KEY7/PC13 | 无 | 点按启停，长按1秒换向一次 |
| 旋钮PG2/PG3 | 无 | 每格±5RPM |

KEY6单击会等待350ms多击窗口，双击不会先减再加。上下限0～400RPM；默认400在上限，所以加速无变化，可先调200。手势无排他仲裁：同时授权时KEY6可能令舵机扫描并改变电机目标，这是明确的广播语义。仅调PID建议STS OFF。实体和`@key`模拟使用相同电平消抖/事件路径；旧F5和蓝牙A/B手势也受STS授权。直接的`@motor enable`、舵机运动帧及屏幕执行指令不依赖按键权限，它们属于显式操作。

## 二、VOFA接线和接收设置

本版本的电机波形走HOST USART1，使用USB-TTL适配器连接开发板已分配的HOST TX/RX并共地，串口设115200、8数据位、无校验、1停止位。HOST物理引脚以[外设接线表](../../引脚与接线/README.md)中USART1为准。此前电脑上CH340为COM12，H743原生USB CDC为COM11；重插后以设备管理器为准。原生USB用于相机图像/文字诊断，本版本没有将JustFloat发送到CDC。

1. 关闭占用HOST串口的软件，在VOFA选USB-TTL对应COM、115200；发送框设ASCII文本，末尾CRLF。禁止把`@`命令按HEX发送。
2. 接收协议选JustFloat；添加曲线控件，绑定接收通道。名义50Hz，每帧8个32位小端float和00 00 80 7F尾，共36字节。不是CSV/FireWater。
3. 先停机设置，再输入`@motor plot on`；或者在屏幕DEBUG页将PID plot ONLY打开。若TX busy，等当前文字发送完成后重发。
4. 绘图打开后，HOST只输出电机波形：文字回复、状态/帮助/旧二进制回复不会混入，但命令仍正常接收执行。此时看不到ASCII应答是预期行为。需要文字时发送`@motor plot off`；或用另一条原生USB文字连接查询。不要让图像接收程序和串口助手同时占用同一个CDC端口。
5. `@quiet`关闭波形及其他周期流，**不会停车**。关闭图像窗口/VOFA也不会自动停车；离开前先发`@motor disable`。

| 通道 | 含义 | 单位 |
|---|---|---|
| 0 | 用户目标，带期望方向符号，停机仍可保留 | RPM |
| 1 | 滤波后的真实反馈 | RPM |
| 2 | PID实际参考，包含斜坡；禁能/换向等待时0 | RPM |
| 3 | 未滤波真实反馈 | RPM |
| 4 | 带方向PWM | 千分比，950=95% |
| 5 | PID参考−真实反馈 | RPM |
| 6 | 电机启用 | 0/1 |
| 7 | 故障码 | 0正常，1无反馈 |

调PID主要比较通道1和2，同时看通道0、4、7。没有电机运动时，曲线应接近0，不应把用户目标当成实测。

## 三、复制发送的自测

以下每行单独发送，按顺序检查。物理授权只用于映射输入，不替代保护。先让电机空载固定好、准备切断VM的手段。

```text
@quiet
@motor disable
@debug sts off
@debug motor on
@input mode mixed
@motor status
```

如果显示fault非0，先排查原因，再手动`@motor clear`。故障不会因授权或开启曲线而自动清除。确认接线/供电后设置初始目标，例如200；此前400测试未形成持续运动，所以没有已验证的400RPM PID效果。

```text
@motor rpm 200
@motor plot on
@key 5 tap
```

按KEY5或模拟命令单击后启用，再按单击停用。KEY6单击减速；双击方法：发送`@key 6 tap`，约200ms后再发一次（第二次要在第一次松开后350ms以内，不能两个命令无间隔发送）。也可用`@knob -1`/`@knob 1`模拟旋钮。

```text
@key 6 tap
@knob -1
@motor disable
@motor plot off
@motor status
```

后两条停机/关图后恢复文字，检查fault/rpm/count。若继续仅抽动并fault=1，停止重复启用，检查动力电源、A通道接线、霍尔供电及A/B；不能靠清故障、调大增益、延长保护来证明正常。只看软件模型无法确认这些实物问题。

PID参数只允许停机修改，单位为千分之一；例子：

```text
@motor disable
@motor pid 1800 5000 0
@motor rpm 200
```

表示Kp=1.8、Ki=5.0、Kd=0，并非针对现有负载已调好的增益。每次只改一项，再启用观测；保存开机默认值需通过既有参数保存页面操作，不会保存授权/波形开关。

## 四、10.3V供电边界

用户最新报告已将VM改为使用中的10.3V电源，本轮未测量。MG310铭牌7.4V，商家表给建议7～13V；10.3V不能证明其电流足够，也不能证明转速600一定安全。初次排障优先使用稳定的7.4V动力电源，检查空载和温升。TB6612逻辑VCC仍3.3V，VM独立供电并共地，绝不把10.3V接到开发板3.3V或编码器VCC；M+/M−只接AO1/AO2。

TB6612不是电流闭环驱动，不能把短时峰值电流当连续额定。现有软件有无反馈/方向/超速/时序保护，没有电流采样或硬件限流。先前50RPM两次及400RPM一次均触发无反馈保护，400目标时参考最高约111RPM、PWM约40.7%，不是已经达到400后才停机。此前实测失败证据保留在[上一版记录](../20261023_VOFA调速与波形/README.md)。

## 五、维护时如何增加调试项目

业务权限集中在`input_control.h`/`bsp_key.c`，业务处理必须在共享输入之后检查自己的权限。屏幕DEBUG通过UiPort命令20～23切换状态；显式串口`@debug sts/motor on/off`调用同一个Input_DebugSet。新增设备需同时扩展权限位、屏幕项、文本解析、帮助目录和按键CSV/JSON，并验证“两个同时开启”“默认关闭”“按住时禁止改授权”“退出页面仍有效”。

波形通道集中motor_plot.c，普通输出经过VOFA_Protocol的独占门控。新增曲线应更新通道数、帧长、接收端表格及编码测试，不要另写printf周期任务绕开门控。教学上将授权、动作、遥测分开：授权决定谁接收输入，动作控制执行器，遥测决定电脑收到什么。
