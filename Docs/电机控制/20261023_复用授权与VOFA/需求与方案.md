# 复用授权与VOFA方案
KEY1～4保持菜单导航。KEY5/6向所有已授权业务广播，不采用独占模式。STS与电机授权独立，启动默认为OFF；离开页面不撤销授权，复位不恢复授权。显式运动命令不受按键授权限制。
KEY5单击启停电机，KEY6单击减5RPM，双击加5RPM；STS仍处理其既有A0/B0手势。KEY7保留原短按启停/长按1秒换向作为电机补充输入，随电机授权门控；旋钮也门控。
快捷键KEY3+KEY4跳至DEBUG页面，再按精确恢复原路径；普通返回遵守主页层级。授权修改要求复用按键全部释放，清除旧排队事件，避免旧手势跨授权执行。
调试页PID plot ONLY选择名义50Hz八通道JustFloat独占HOST，普通回复不能污染波形；USB诊断仍可用。不绘图默认静默，@motor plot off恢复文字，@quiet关闭全部流但不停止运动。
本轮不连接ST-Link、串口，不启动电机；10.3V是用户报告VM，未实测。保留之前50/400RPM无反馈失败证据。
