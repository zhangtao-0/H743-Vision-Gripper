## 操作与接线

[VOFA旋钮、启停和PID曲线教程](../04_VOFA旋钮按键与PID曲线.md) / [H桥原理制作与TB6612实接](../05_H桥原理制作与TB6612接线.md)。KEY7改为点按启停、长按1秒换向；VOFA用@key 7 tap和@key 7 press 1200，旋钮用@knob 1/@knob -1与实体共享5RPM增量。

工厂目标400RPM，保持上电禁能；普通禁能保留目标，@motor stop/故障仍清零。参数21工厂值同步到屏幕和映射表，旧自定义开机配置不覆盖；需改自己的开机目标时停机设置并保存。

新增@motor plot on/off/status及@motor disable；JustFloat在HOST名义50Hz发送8通道，用户目标/滤波实测/PID参考/原始实测/PWM/误差/启用/故障。USB保持文字诊断；绘图期间HOST拒绝混入其他原始回复，关闭后恢复。图像CDC不作为这条波形通道。@quiet关闭波形但不停止电机。

当前驱动分配：PWMA PB14/U9-45、AIN1 PE10/U9-37、AIN2 PE12/U9-39、STBY PE13/U9-40；逻辑VCC=3.3V，VM独立动力。PG2/PG3旋钮A/B、PC13按压，PE9/PE11霍尔反馈。GPIO空闲数仍37，原4个H桥条件预留改为源码已分配；实物状态另记。
