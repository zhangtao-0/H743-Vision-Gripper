# H桥原理、自己画板的方法与TB6612实接

## 1. H桥为什么能让两根电机线正反转

有刷电机需要的是M+与M−之间的电压差。把两端互换，转矩方向就反过来；改变通断比例，可以改变平均驱动效果。H桥用四个功率开关，电机放在两条桥臂中间：

```text
                VM（电机电源正极）
                │               │
             Q1上左          Q3上右
                │               │
                ├── M+ 电机 M− ─┤
                │               │
             Q2下左          Q4下右
                │               │
                └──── GND ──────┘
```

Q1+Q4导通时电流向一个方向流；Q3+Q2导通时相反。所有开关关闭可进入滑行；两端被接到相同电位可以形成制动。PWM是在安全的开关组合之间快速切换，PID计算占空比，H桥承担实际的安培级动力电流。

同一桥臂的上下管不能同时导通，例如Q1+Q2，否则电源会被直接短接，这叫直通。反转也不能仅把四个GPIO立即翻过来，需要关断、死区及对电机残余电流的处理。感性电流还需要续流路径；MOSFET体二极管、驱动芯片的开关策略及电源吸收能力共同参与，不能把电机当电阻。

## 2. 你已有TB6612，先用模块完成项目

TB6612内置了两组H桥、栅极驱动等电路，使用一个A通道就能控制一台MG310，不需要再手焊四只功率MOS。

[东芝原厂数据表](https://toshiba.semicon-storage.com/info/TB6612FNG_datasheet_en_20141001.pdf?did=10660&prodName=TB6612FNG)给出的工作范围为逻辑VCC 2.7～5.5V、动力VM 2.5～13.5V；本项目VCC选3.3V，VM先用现有4.5V，后续按MG310额定7.4V配置动力源。控制输入高电平门限与VCC成比例，VCC若接5V，3.3V GPIO不能保证满足其最小高门限，所以这里明确使用3.3V逻辑供电。

电流不能只看广告里的3.2A：该值对应短时单脉冲条件。数据表工作范围在VM≥4.5V时列1.0A输出；绝对最大1.2A也不能当作任意小模块持续工作的保证。MG310额定电流截图≤0.5A、堵转≤2A，故应有电源限流/适当保险与散热，并避免堵转。TB6612没有可编程恒流调节接口，软件300ms无反馈停机也不能替代硬件限流。

## 3. 按设备接线表

先断电，**M+/M−从4.5V电源板断开，改接驱动输出**。电源板改给TB6612的VM供电，MCU不承受电机动力电流。

| TB6612 A通道信号 | 接哪里 | 含义 |
|---|---|---|
| VM | 电机电源正极，当前4.5V | 动力，不接H743 GPIO或3.3V输出 |
| VCC | H743 3.3V，例如U9-1/2 | 逻辑供电 |
| GND | 电源负极＋H743 GND | 信号共同参考；动力回流不要绕经细GPIO地线 |
| AO1 / A01 | MG310 M+ | 功率输出 |
| AO2 / A02 | MG310 M− | 功率输出 |
| PWMA | PB14 / U9-45 | TIM12_CH1，20kHz |
| AIN1 | PE10 / U9-37 | 方向控制1 |
| AIN2 | PE12 / U9-39 | 方向控制2 |
| STBY | PE13 / U9-40 | 低电平待机，启动时才拉高 |
| BIN1、BIN2、PWMB | 未用通道输入接GND | 不让未用输入悬空；BO1/BO2不接电机 |

如果模块把AO1写成A01或把电源标成其他名字，先按模块原理图核对，不按排针位置猜。所有GND应相连；不要把VM与逻辑VCC短接，也不要将STBY固定接高而绕过当前软件禁能方案。

MG310霍尔A仍是PE9/U9-36、B仍是PE11/U9-38，编码器VCC仍用3.3V、GND共地。这两根反馈线与TB6612的AIN1/AIN2是不同概念，名字都有A/B但不能接到同一位置。

## 4. 这套固件怎样使用TB6612

配置位于motor_config.h的`MOTOR_DRIVER_PROFILE=2`，对应PWM+IN1+IN2+STBY；GPIO集中在board_devices.h。上电PWM=0、STBY=低，目标400也不会自动转。

| 软件输出 | STBY | AIN1/AIN2 | PWMA | 效果 |
|---|---|---|---|---|
| 0/禁能 | 低 | 低/低 | 0 | 输出待机、高阻滑行 |
| 正值 | 高 | 高/低 | 占空比 | 请求一个方向 |
| 负值 | 高 | 低/高 | 占空比 | 请求相反方向 |

“正向”是软件定义，仍需用低速试验核对电机和霍尔符号。PWM通断期间芯片内部会按真值表处理续流/短路制动，不能把这个表当作四只裸MOS栅极的控制表。软件换向先进入滑行并等待低速；等待超时会报故障，不强制反向。

## 5. 想自己制作PCB，需要增加哪些东西

用TB6612芯片画自己的小板，可以按下面责任拆分，而不是只把芯片和两排插针画上：

1. **电源入口**：VM和逻辑3.3V分开，放明确丝印、极性保护/保险与测试点，电源线和插座按启动电流选型。
2. **去耦与储能**：按原厂应用图在VM、VCC附近放陶瓷去耦和储能电容；长电源线或快速制动还需评估母线电压上冲。电容耐压按最大动力电压和瞬态留余量，不能只按当前4.5V挑。
3. **默认关闭**：STBY有明确下拉；PWMA和方向线保持已知状态。MCU复位、未烧录或拔掉控制线时，电机也应保持关闭。
4. **功率布线与散热**：VM、输出、动力地短而宽，芯片周围铜皮散热；霍尔线、旋钮线和时钟线远离PWM电流回路。不是用一条细地线串联所有负载。
5. **接口隔离清楚**：电机M+/M−、编码器VCC/GND/A/B、控制PWM/IN/STBY分组，提供防误插说明；留VM、3.3V、GND、输出和控制信号测量点。
6. **校核与首板上电**：核对封装方向、供电脚、未用通道、器件耐压和温升；限流上电，先不接电机确认STBY/PWM，再接空载电机低速验证。随后才测试方向、负载和PID。

若一定要用四只独立MOS搭H桥，还需选高低侧驱动器、计算栅极电压与充放电、安排死区、核算MOS导通与开关损耗、验证续流和过流关断。高边N-MOS的栅极驱动通常不能直接由3.3V GPIO替代。可以把它作为后续电力电子实验，但当前机械臂项目优先用已有TB6612完成闭环，避免同时调试未知功率板与PID。

## 6. 上电验收顺序

先逻辑供电确认3.3V和公共地，再测动力VM。保持软件未使能时观察电机应不被TB6612驱动。用手慢转电机轴，确认真实计数变化；然后先设50RPM、点按启用，核对方向，正常停止；最后逐步增加速度并看实测/目标/PWM三条曲线。

当前4.5V下400RPM未必可达；转速达不到不表示H桥接错或PID一定错误。先看PWM是否饱和、电源是否掉压，再评估动力电压与负载。测得温升异常或电机卡住，应先切断动力源，不能只反复清故障重启。

## 现场常见混淆：电机为何仍然不动

PE10/PE12连接AIN1/AIN2，是方向指令；PE9/PE11连接电机霍尔A/B，是转动反馈。两组A含义不同，不能互接。H743的3.3V连接VCC只使逻辑工作，独立电机电源正极应接VM，负极接GND并与H743共地。当前首次试验没有转动、触发无反馈，独立VM供电待补接；见[现场说明与实测曲线](20261023_VOFA调速与波形/现场供电与方向接口澄清.md)。
