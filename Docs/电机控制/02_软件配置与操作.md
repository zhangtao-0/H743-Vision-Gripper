# 配置与操作

## 分层

- `motor_control.*`：不依赖 HAL 的速度估计、PID、斜坡、反向等待、异常状态及 EC11 Gray 解码。
- `motor_service.*`：1ms 旋钮/按键采样，每 10ms 读取 TIM1 增量并运行速度闭环；快照、命令与 ISR 的共享状态通过保存/恢复 PRIMASK 的短临界区保护。
- `board_motor.*`：TIM1 编码器、TIM12 PWM、TIM6 调度与 H 桥接口；GPIO 统一取板型配置。
- `integration_service/console`：初始化、串口/USB 控制台和 LCD 状态行；不改变 STS 协议。

PID 固定 100Hz，不依赖摄像头/SD 任务的主循环间隔。TIM6 中断优先级 5，低于 UART、高于 DCMI/DMA；ISR 不打印、不延时、不访问文件系统。中断间隔异常超过 50ms 时在恢复执行后停止输出，不能替代硬件看门狗/电流保护。

## 集中配置

`project/App/config/motor_config.h`：

| 配置 | 默认值 / 意义 |
|---|---|
| MOTOR_DRIVER_PROFILE | 2，TB6612 A通道；0仍为无驱动禁止启动 |
| MOTOR_DEFAULT_RPM | 400，工厂目标；上电不自动使能 |
| MOTOR_ENCODER_GMR | 0 霍尔 13PPR；1 为 GMR 500PPR |
| MOTOR_GEAR_RATIO | 20.409 |
| MOTOR_ENCODER_SIGN | -1；2026-10-24实测正向驱动时原始TIM1计数递减 |
| MOTOR_OUTPUT_SIGN | +1，功率输出方向；只改变 H 桥方向定义 |
| MOTOR_MAX_RPM | 400 RPM，应用限速 |
| MOTOR_KNOB_EDGES_PER_DETENT | 4，另支持每格两边沿的 EC11 |
| MOTOR_KNOB_STEP_RPM | 5 RPM/格 |
| MOTOR_KP / KI / KD | 1.8 / 5 / 0；初始调参值，尚未经实机调参 |
| MOTOR_PWM_LIMIT | 950‰，95% 最大占空比 |
| MOTOR_RAMP_RPM_S | 1000 RPM/s；0→400参考斜坡约0.4秒 |
| MOTOR_SPEED_FILTER | 0.25，一阶测速滤波 |

20kHz PWM 使用 20MHz 计数、ARR=999，支持千分比占空比。PID 为带积分限幅和条件抗饱和的并联形式，微分作用于测量值以减少目标跳变冲击；默认 Kd=0，即先用 PI 调速，Kd 可配置。

## 人机控制

上电停机、工厂目标400RPM，已保存的开机配置优先。SM0488050旋钮调整速度幅值；点按启停、长按1秒换向。旋钮在停机时只改目标，不会自动启动；驱动profile0时点按/命令启动均拒绝。

换向时输出先归零，实际原始速度连续 100ms 小于 10 RPM 后才改变输出方向并重新爬升；3s 仍未停稳则锁定换向超时故障。停机/目标为零清 PID 积分；故障清除后仍停机，必须显式重新启动。

若输出≥20%、请求非零且 300ms 无编码器增量，则反馈故障停机；反馈方向持续错误 200ms 也停机。这只是异常检测，不能当成允许堵转的依据。低速稳定度受分辨率、死区、负载和实机 PID 参数影响。

LCD 倒数第二行 `M` 为目标 RPM、`R` 为带符号实际 RPM、`D` 为目标方向、`E` 为故障码。底行仍显示原 STS 状态。电机故障时 PG1 故障灯改为 5Hz 快闪，清故障后回到原系统指示逻辑。摄像头预览可覆盖其区域，可用 `@camera off` 获得稳定的状态显示。

## 控制台

UART HOST 或 USB CDC 输入实际回车/换行结束：

```text
@motor status
@motor rpm 100
@motor enable
@motor reverse
@motor stop
@motor clear
@motor zero
@motor cpr 1061
@motor pid 1800 5000 0
```

`enable` 需要已配置驱动、有效 CPR、硬件初始化成功且无故障；`stop` 立即取消使能、目标归零；`clear` 清故障但不会启动。`cpr`、`pid`、`zero` 仅停机时允许。PID 命令参数为实际增益 ×1000。整数 `cpr` 用于手转实测标定；默认编译值保留精确 1061.268，不必为默认霍尔版执行整数覆盖。

`status` 中 `rpm10` 为实际 RPM×10，`pwm` 为有符号千分比，`cpr1000` 为 CPR×1000，`count` 为累计有符号计数。故障码：0 正常、1 无反馈、2 换向停稳超时、3 反馈方向错误、4 控制定时异常。

电机已使能时，现有 SD/QSPI/LCD 测试、摄像头重初始化等维护命令会拒绝执行；先 `@motor stop` 再维护。

## 手转核对与首次闭环

1. 无动力驱动时可先接编码器 3.3V/GND/A/B 和 EC11，保持 M+/M- 未接电源。烧录后 `@motor status` 应 `ready=1 driver=0 on=0`。
2. `@motor zero` 后缓慢手转输出轴整整一圈。霍尔计数应约 ±1061，GMR 约 ±40818。此操作还能检查 A/B、型号和转向；不是手转电机内转子一圈。
3. 安装选定 H 桥，按其真值表设置 profile；保持 7.4V 动力和 3.3V 编码器电源分开、共地。先从低速空载验证反馈符号，若符号错立即停机并修正配置。
4. 从 50–100 RPM 开始，以 `@motor status` 或 LCD 检查实际速度，再调 Kp/Ki；出现振荡或饱和先降增益/目标，不进行机械堵转测试。
5. 实机稳速验收记录目标/实际 RPM、负载、电源电压、驱动型号、CPR、增益、稳态误差和响应；本轮仿真结果不能替代这些记录。

当前VOFA曲线、旋钮模块电平及启停语义以[操作教程](04_VOFA旋钮按键与PID曲线.md)为准；配置与物理验收分开记录。
