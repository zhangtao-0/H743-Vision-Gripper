# 5V对照依据与边界

用户此前提供MG310霍尔参数表为3.3～5V，且默认输出上拉至VCC。当前3.3V实际驱动时无有效正交脉冲。仅作为供电对照，不认定3.3V规格不真实。

ST STM32H743xI数据手册：PA8为FT_fha，PE11为FT_ha，AF1分别TIM1_CH1/CH2。在当前数字AF、MCU持续上电状态可接收规定范围的5V数字输入；数据手册要求输入高于低电源域+0.3V时关闭内部上下拉。因此本版本为GPIO_NOPULL，依赖编码器已有输出上拉，不把5V直接给普通3.3V引脚。

仅编码器VCC从3.3V改为开发板+5V/U9-3或4，A/B为已确认FT脚PA8/PE11，GND共同；10.3V不接编码器或GPIO，L298N5V-EN保持原样。切线时VM先断开，H743保持USB，软件禁能。没有万用表，板端+5V是标称值，尚未实测。

主证据：https://www.st.com/resource/en/datasheet/stm32h743zi.pdf 。当前抓取快照.firecrawl/20261024-stm32h743-pa8-af.md包含引脚表及5V容限/上下拉条件。
