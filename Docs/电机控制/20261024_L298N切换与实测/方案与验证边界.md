# L298N切换方案

用户改用L298N，TB6612仅为疑似故障，未测电压不能确认损坏。正式默认驱动切profile1（PWM+IN1+IN2），PWM/方向沿用PB14/PE10/PE12，PE13/STBY停用并保留给未来TB模式。TIM1霍尔和TIM12 PWM及PID保护不改。

L298N的VSS应5V（ST数据手册4.5～7V），输入高最小2.3V，3.3V控制线可用，但不能3.3V给VSS供电。ENA调速跳帽拔除；5V-EN是不同的稳压跳帽，具体模块先确认，不能把5V端接H7433.3V。动力10.3V是用户报告未测。M+/M−接OUT1/2，霍尔A/B仍PE9/11、VCC3.3V、GND公共地。

ST-Link当前DEV_CONNECT_ERR，未具备新固件烧录条件；原profile2额外驱动PE13，如果PE13断开且ENA/IN1/IN2正确接入L298N，可按电气兼容接口短测旧固件，但单独记录，不称新profile1已烧录。物理接线及5V逻辑未确认前不启动。

已备份旧配置和引脚主数据。构建、主机测试、正式引脚表和实物状态分别记录。每次实际运行保留数据，finally禁能，不绕过无反馈/方向/超速保护，不因换板清掉旧失败证据。
