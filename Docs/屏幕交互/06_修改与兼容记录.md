# 本版修改与兼容记录

当前screen-ui-v2的分类帮助、独立图像查看、旋转/镜像与静默行为见[本轮修订](20261022_交互与图像修订/README.md)。下面初版叙述保留原设计背景；以当前操作手册为准。

## 源码变化

新增UI目录，分别实现导航、输入、端口、显示、开机配置服务、纯记录格式与H7存储。App/Integration接入初始化、按键采样、显示任务及STS就绪后的参数应用；BoardCamera新增独立预览窗口；电机服务新增维护门控和原子参数应用；STS owner末尾追加SCREEN，保留旧枚举编号并显示UI来源。

KEY3/4从原预览/报告改为菜单，BOARD_ENABLE_UI可关闭菜单，禁止和KEY3/4实体PWM模式同时启用。电机驱动profile未修改，仍为0。新增25字小字库，未引入外部GUI框架或轮腿车代码依赖。

IAR三目标增加UI源文件/头目录，ROM上限从0x081BFFFF缩至0x0817FFFF，独立保留Bank2扇区4/5给开机配置；原限位6/7位置保持。固件当前体积远低于该边界；实际地址分布由map/HEX核对。

## 与旧指令文档的关系

没有新增`@ui`或更改F0–F5字节布局。菜单复用已有参数/动作API，并增加显式SAVE/LOAD/CLEAR开机配置入口；这些不是已有串口命令的自动别名。普通F2/@motor参数仍先改RAM，但可以随后用菜单SAVE收录支持字段。

`@camera on`在菜单模式下开启采集并解除LCD测试占用，仅CAMERA观测页绘图；关闭UI时仍按旧全屏预览行为。`@lcd test`临时显示测试画面；下一次菜单手势只恢复UI不执行其他业务。

## 快照与回退

实施前[源文件哈希](实施前源文件.json)、[代码备份](../../Backups/project_pre_screen_ui_20261022.zip)保存本轮开始状态。实施后[源文件变更](源文件变更.json)标明新增/修改；原教学基线和指令快照在备份中保留，当前引用只对受影响文件重新定位和更新。

本轮是实际固件研发，不能沿用前两次“仅文档、生产源码不变”的结论。旧教学说明与指令整理阶段的证据仍按历史语境保留；当前版本以本版构建哈希与验收表为准。未刷新任何历史实物通过结论，也没有自动烧录。

只有明确要回退时才从备份恢复必要源文件/链接配置并重建；不能把整份工作区覆盖到旧状态。关闭BOARD_ENABLE_UI只关闭菜单，不自动删除Flash中的开机配置；要弃用它应先按明确策略清除或调整设置加载。

## screen-ui-v2

当前主页增加分类指令帮助与独立图像查看，常用指令改为分类执行。默认串口静默，支持RAM拍照、边缘预览、独立LCD与图像方向、开机方向保存和电机超速保护。[本轮源码、兼容与验收记录](20261022_交互与图像修订/README.md)取代上面初版CAMERA页显示图像等行为说明。
