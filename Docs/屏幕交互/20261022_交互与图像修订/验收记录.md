# 本轮软件验证与实物验收

本轮使用实际C导航、记录格式、H7存储代码、摄像头路径、控制台和电机服务做主机测试。主机测试证明逻辑，不代表外设波形、屏幕或电机已经实物通过。

| 项目 | 本轮核验范围 |
|---|---|
| UI | 分类动作与实际指令映射、帮助只打印、独立图像所有权、快捷路径恢复、编辑冲突/确认/取消 |
| 配置 | 精确CPR、方向保存/重启恢复、机械端点不覆盖、打印开关不随旧配置恢复、5个Flashword掉电位置/CRC/双槽 |
| Camera | DMA不完整/错误帧拒绝；16种旋转/镜像/翻转组合逐像素比对；RAM冻结/恢复；原始帧不变；边缘路径执行 |
| Console | 静默取消周期流、按需分批帮助、闲置不自动打印；旧二进制隔离、双通道、超长/超时/邮箱边界和维护门控 |
| 电机 | PID负载模型、换向等待、无反馈/反向/调度/持续超速故障；无H桥启动禁止；四种驱动profile编译 |
| 目标构建 | H743_VisionGripper、OV2640、NoCamera三配置；日志与HEX地址范围由本版审核脚本核对 |

[UI测试](../主机状态机测试.json)、[配置测试](../主机开机配置测试.json)、[Flash模型](../主机配置Flash模型测试.json)、[摄像头回归](../../故障排查/20261021_花屏与舵机离线/摄像头主机测试.json)、[控制台回归](../../整合交付/整合主机测试.json)、[本版构建核验](../本版核验结果.json)。

实物待验：上电与闲置串口无刷屏；屏幕帮助分类正确；夹取/松开行为和限位；相机全视野、颜色、16种方向/翻转与LCD四方向；多次进出无花屏；RAM拍照是否冻结；断电后方向恢复；电机编码方向、PWM/换向/故障阈值、供电和真实PID。照片落盘、自动抓取、直线拟合不属于已实现项目。

本轮没有新增烧录，也没有将历史实物验证记录沿用到本版HEX。
