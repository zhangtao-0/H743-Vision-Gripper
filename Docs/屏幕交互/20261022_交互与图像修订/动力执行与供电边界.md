# H743侧动力执行与供电边界

用户将按设备指定范围供电；本页明确程序做什么、硬件仍负责什么。供电范围见[硬件档案](../../硬件档案/README.md)。

## MG310霍尔编码器电机

当前接线规划仍是A/B→PE9/PE11 TIM1编码器；EC11→PG2/PG3，按压PC13；H桥预留PB14/PB15和PE10/12/13。H桥尚无已安装证据，profile0保持功率输出关闭；电源接好并不能让MCU直接驱动M+/M-。

H743的完整软件链路：1ms定时中断处理EC11/按键，累计10ms读取计数差；使用CPR换算输出轴RPM并滤波；目标斜坡→PID→限幅PWM→H桥平台层。霍尔版CPR=4×13×20.409=1061.268，替换GMR必须相应改CPR。CPR/PID修改要求停机，恢复开机目标不会自动使能。

换向先将PWM归零，等待原始测速低于10RPM且连续100ms，再改变方向并重新爬升；3秒仍未停则锁故障。已有保护还包括：高驱动下无计数300ms、反馈方向错误200ms、1ms中断出现超过50ms间隔。故障停输出，手动清除不启动。

本版新增MOTOR_FAULT_OVERSPEED（编号5）：使能时原始测速持续100ms超过 `max_rpm×1.5+30`，停机并锁故障。当前max_rpm400对应630RPM；这是反馈合理性/超速软件保护阈值，不是电机允许额定转速的重新定义。CPR/噪声错误也会触发，实测时先核对计数方向、CPR和滤波。

屏幕“执行控制→MG310”可停止、清故障、使能、反向；参数页调目标RPM/PID，观测页看目标/实测/计数/故障/PWM。EC11短按换向、长按800ms启停的旧操作保持。

## STS与PWM舵机

STS继续通过在线反馈、限位、状态机、转矩/速度限制与停止检测工作；屏幕夹取/松开调用同一业务层。离线或限位未就绪拒绝动作。C001最高电压寄存器写入守卫从旧11.7V改为7.4V，防止通过本地守卫写出当前型号资料范围；没有自动写舵机EEPROM，也没有替换用户实物供电。

STS反馈的电压/电流属于舵机设备测量值；要结合有效/在线状态解释。普通PWM舵机没有通过单根信号线回传位置/电流，本版不伪造测量；其负载保护要靠实际硬件/额外传感器和机构设计。

## 目前没有测量的内容

MG310没有新增电流传感器、分压ADC或驱动FAULT输入绑定，所以H743不能凭编码器确认实际电源电压、电流和驱动温度。编码器无反馈/超速保护不能替代H桥限流、短路/过温保护或保险丝。

选定H桥后再绑定其真值表、3.3V输入、PWM有效电平、待机与硬件故障接口。若要求软件欠压/过流停机，需要补电压/电流采样或可读驱动器，校准后再加入故障状态机；当前不显示虚构的“供电正常”测量结果。

## 首次上板顺序

先无动力核对ENC/EC11/按键与默认PWM=0；手转核对正负计数；安装已核验的驱动与合规电源，低速空载验证启动/停止/换向，再调PID与加负载。对停止、断反馈、错误方向和失联/调度故障逐项验收。电机、舵机电源与MCU供电路径仍按档案分别核对，避免动力回灌开发板。
