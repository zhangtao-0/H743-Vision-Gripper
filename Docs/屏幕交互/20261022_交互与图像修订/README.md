## 对应六项需求

| 需求 | 当前实现与入口 |
|---|---|
| 默认不自动打印 | 关闭P3周期遥测和上电日志；不从开机配置恢复CLAW_PRINT=1；CSV原本默认关闭；`@quiet`可再次停全部周期流 |
| 分类打印指令 | 主页“指令帮助”：系统、夹爪、电机、相机、PWM、存储/时钟、二进制协议；选分类KEY4后向HOST和USB输出，逐循环一行 |
| 常用动作可执行 | 主页“执行控制”按夹爪/电机/相机/PWM/系统分组；动作有确认页与业务状态检查；自动夹取显示NOT IMPLEMENTED，不发送动作 |
| 按需看图像 | 主页“图像查看”→实时图像，或拍摄下一完整帧并冻结在RAM；退出后相机不再覆盖菜单；观测CAMERA页只显示诊断 |
| 独立方向控制 | LCD文字方向每次+90°；图像单独+90°、左右镜像、上下翻转；不改原始采集帧；SAVE开机配置可保存方向 |
| H743侧电机/舵机保障 | 保留霍尔测速、PID、斜坡、换向等待、无反馈/符号/调度故障、无驱动禁止启动；新增持续超速反馈故障；C001最高电压寄存器写入守卫从11.7V收紧到7.4V |

## 明确功能层级

拍照是“下一完整RGB565帧留在RAM”，没有自动生成SD卡照片、JPEG或上传文件。实时显示240×144窗口内居中144×144完整画面，两侧留黑，保持比例；不再只截取原始画面上方144行。

Edge preview用相邻像素亮度梯度、固定阈值生成黑白边缘预览；没有直线拟合、物体定位、标定或闭环抓取。离开图像查看仍可采集，边缘仅在预览绘制时计算。自动夹取需要后续机械臂节点、相机标定、视觉位置与动作规划，当前禁止执行。

本版测试区分主机逻辑、IAR构建和实物验证，具体结果见[验收记录](验收记录.md)。
