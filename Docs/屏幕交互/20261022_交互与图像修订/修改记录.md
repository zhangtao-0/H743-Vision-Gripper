# 修订、兼容与回退记录

- 默认关闭P3遥测、上电主提示、初始化厂商日志；显式查询保留；开机/LOAD不恢复CLAW_PRINT启用状态。
- 主页4项扩为6项；执行控制按设备分类，新增独立帮助和图像菜单。快捷目标仍是观测，原索引3保留，恢复路径/草稿/选择不变。
- 图像从CAMERA观测页移到图像查看页；保持DMA完整性检查及AXI非缓存帧区，新增约1920字节4行暂存，不增加第二个完整帧缓冲。
- RAM拍照请求下一完整帧；冻结后允许重绘/变换；显示旋转与镜像不改变原始帧。边缘是轻量梯度预览，完整抓取未实现。
- LCD使用既有四方向驱动映射；240×240面板偏移和实际方向须实物确认，不能用主机测试替代。
- 开机记录保持160字节、版本1与Flash分区；reserved[0]新增VIEW标记，reserved[1]低6位保存LCD四方向/图像四方向/镜像/翻转。旧记录预留位为0时按方向0加载；CRC覆盖扩展字段。旧版固件读回会忽略这些方向信息。
- MOTOR_FAULT_OVERSPEED追加到枚举末尾，旧故障编号不变；保护持续100ms锁停，清故障不启动。H桥profile仍为0。
- C001电压写入守卫74（0.1V单位）替代旧117，记录此前不同后缀默认上限过宽的问题；本次不向设备写配置。
- 原二进制帧格式保持，新`@`分支见指令手册。命令目录、函数行号/哈希、页面模型与构建证据按触及文件更新，旧证据可从修订前备份恢复。

回退代码与工具使用 `Backups/pre_ui_v2_20261022.zip`；用户原ESP8266程序与多控制器规划不在改动范围。回退固件时注意开机配置扩展字段兼容以及现有机械限位的独立扇区，不做整片擦除。
