# H743 初版屏幕菜单与快捷观测

本版按用户指定的[轮腿车codex分支](https://github.com/207-Smart-Cat/WHEEL_LEGGED_207/tree/0cf70fb0120a53d5c7caf75cd276cb3a366e8522)借鉴页面组织思路，自行实现导航、按键、业务适配和显示服务。代码已接入H743工程；初版历史证据保留；当前四键修订版已烧录，实体按键/屏幕肉眼观察/Flash掉电验收尚未完成。

主页提供：**参数调节、执行控制、默认参数、运行观测、指令帮助、图像查看**。KEY1～4分别用于上下确认取消；KEY3+KEY4两键同时按下在观测页与原页面之间快捷往返，保留列表位置、编辑草稿和确认状态。观测页有系统、STS、MG310、摄像头诊断4个子页；图像单独从图像查看进入。
