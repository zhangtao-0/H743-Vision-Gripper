# 构建、模型测试与实物验收边界

当前screen-ui-v2的分类帮助、独立图像查看、旋转/镜像与静默行为见[本轮修订](20261022_交互与图像修订/README.md)。下面初版叙述保留原设计背景；以当前操作手册为准。

## 本版已完成的软件检查

- 三种IAR目标：H743_VisionGripper、OV2640、NoCamera；对应[默认日志](构建_default.log)、[OV2640日志](构建_OV2640.log)、[NoCamera日志](构建_NoCamera.log)。结果与固件哈希集中在[本版核验结果](本版核验结果.json)。
- [导航/输入/记录测试](主机状态机测试.json)：实际C模型的快捷完整恢复、正常返回、滚动、草稿冲突、取消优先、组合释放抑制、计时回绕、CRC/版本与序列。
- [配置服务测试](主机开机配置测试.json)：启动不写Flash、保存后重启恢复、CPR精度、STS延迟应用、排除机械端点、运动互锁、失败恢复和删除标记。
- [H7存储模型](主机配置Flash模型测试.json)：真实ui_profile_store代码在Windows虚拟地址/HAL故障模型下运行，测试5个Flashword位置中断、CRC回退、BankSwap拒写，确认机械限位扇区不被访问。
- [电机回归](../电机控制/主机测试.json)增加维护门控/配置恢复检查；[摄像头回归](../故障排查/20261021_花屏与舵机离线/摄像头主机测试.json)增加“继续采集但不写LCD”、有界窗口与离页取消绘制；[控制台/PWM回归](../整合交付/整合主机测试.json)保持通过。

静态构建/地址核验：`python Tools/audit_screen_ui.py`。

运行入口：`python Tools/run_ui_tests.py`、`python Tools/run_motor_tests.py`、`python Tools/run_camera_regression.py`、`python Tools/run_integration_host_tests.py`。这些是软件模型，不能代替真实Flash电源故障、屏幕和按键验证。

## 页面模型视觉核对

[初版模型预览](本版页面模型预览.png)由实际UiCore_View输出、当前参数/动作名称和固件ASCII/中文位图生成，检查240×240范围、行高、选择对比与标题。数值和状态来自测试替身，不是开发板采样。重生成使用`python Tools/render_ui_preview.py`。

本轮没有烧录。本版固件与历史用户确认的摄像头版本不同；历史“画面随目标变化”仍只证明历史版本。

## 上板后逐项验收

| 项目 | 操作与应观察结果 | 当前状态 |
|---|---|---|
| 上电主页 | 六类入口、中文标题、无视频覆盖/残留 | 待测 |
| 单键/长按 | KEY3短下长上，KEY4短进入长返回，长按释放不额外触发 | 待测 |
| 快捷完整恢复 | 参数列表滚动→编辑→改草稿→组合→切观测子页→组合，恢复原草稿和位置 | 待测 |
| 常规返回 | 快捷观测中长KEY4→主页；再正常进入，旧快捷上下文不复活 | 待测 |

| 确认与取消 | 默认CANCEL；明确EXECUTE才执行；失败后取消优先；快捷不自动确认 | 待测 |
