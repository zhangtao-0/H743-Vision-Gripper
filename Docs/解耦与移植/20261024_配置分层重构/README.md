# 配置分层重构交付与证据

当前源码已完成配置分层与适配入口重构；六组硬件配置和业务参数分开，提供统一目标/SDK/板型选择。本轮未烧录、未占用串口、未启动任何机构。

## 实施结果

- 目标入口target_config→targets/stm32h743_lxb→SDK/板型/后端；board_profile汇总io、serial、motion、vision、storage、system六组。
- UART的句柄绑定、硬件初始化、GPIO/RCC、NVIC及IRQ统一由角色表驱动，Core不再维护三份MX_USARTx函数；VOFA/蓝牙异步收发经BoardUart。
- KEY1～6逐键电平和上下拉可配置；EC11/KEY7归motion；GPIO时钟跟随配置端口。屏幕逻辑键/模拟输入和授权行为不改。
- LCD、相机、SD、QSPI、USB的引脚/时钟选择/IRQ入口读取对应配置，芯片特有实现仍在适配/厂商驱动层。
- UI开机配置与限位记录通过HAL-free BoardNv区域接口访问存储。H743擦除/Flashword/Cache/分区检查在芯片后端，记录布局和CRC不变。
- 电机API继续用PWM千分比，适配层换算计数；1ms调度、微秒PWM舵机计数契约加编译检查。
- 原有110个板级值已逐项等值核验；108个引出事实、60个宏引脚检查、58项有效GPIO占用及4个独占定时器通过，36个空闲候选数量保持。

## 核验和限制

三种IAR配置按序构建，均0错误0警告；角色改绑与重复资源拒绝模型、GPIO/输入映射、电机、VOFA波形、舵机协议、相机、UI、Flash中断恢复等回归通过。具体最终状态见[验证汇总](验证汇总.json)。构建模型不等于实物验收；新版本未烧录，上一版EC11固件的实测记录保留，不套用到本版。

[UART配置一致性测试](UART配置一致性测试.json)编译真实后端，验证默认配置、只改表后交换HOST/SERVO、重复UART拒绝；[配置与Flash边界测试](配置与Flash边界测试.json)验证别名、错误Bank、程序区地址、非法长度/区域在任何Flash操作前被拒绝，以及缺少DCMI时能力门控。Flash模型还覆盖逐Flashword断写、CRC回退、tombstone、Bank交换和另一记录区不被改写。

## 变更与纠错

1. 以前改board_resources句柄表仍需手改Core/MSP/IRQ，现在统一描述表，旧兼容头只转发。
2. 以前更改GPIO可能忘记开启新端口时钟，现在按配置端口自动使能；逐键有效电平和输入电阻从共享默认扩展为独立字段。
3. 以前UI直接进行H7 Flash擦写，现在记录逻辑与擦写分离。地址、版本、CRC和槽位切换规则保持。
4. 原platform_hal的F103头分支不是完整F103移植，已改成明确目标选择；没有提供未经验证的新芯片可运行配置。
5. 原IRQ/源码定位、引脚表维护脚本仍读取旧两个大配置头，已改为实际六组配置事实；来源哈希和93个函数定位同步。
6. 指令手册源码快照存在一项此前电机配置漂移及本轮结构变更；[差异审查](指令快照差异审查.json)保留历史快照，保持上游来源不变，协议目录及示例检查后更新本地参考。
7. 尝试并行IAR构建时遇到共享清理文件冲突，失败日志保留；改为顺序构建并全部通过，不能把并发失败覆盖成从未发生。
